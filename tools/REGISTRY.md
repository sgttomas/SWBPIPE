# Tool Registry

| Name | Category | Language | Purpose | Inputs | Outputs |
|------|----------|----------|---------|--------|---------|
| `caepipe_correlation` | validation | Python 3 | Run the private external-prover correlation pilot: solve each public case in SWBPIPE, write SI MBF, solve it in the user's configured external prover (DEL-17-05 harness), parse and write the three-way comparison into the private exchange folder; see DEL-17-05 `Work/caepipe-correlation-pilot.md` | `python3 -m tools.caepipe_correlation.run_pilot [--case ID ...] [--offline] [--runner PATH]` with `SWBPIPE_CAEPIPE_EXCHANGE` and `OPENPIPESTRESS_RUNNER_BIN` | Private case folders; stdout reports operational status only; skips with a reason when unconfigured. `check_public_observations.py --terms-file <private> --base <ref>` screens added public text for content that evaluates the external prover (DEL-17-05 Design §8); exit 1 on a finding |
| `caepipe_mbf_import_vectors` | fixtures | Python 3 | Record the MBF importer's parity vectors for its Rust port (DEL-17-04 Design `desktop-mbf-export-import.md` §2, slice 3): every importer call its own test suites make, the invented MBF corpus written back through the SI writer, the writer's regenerated sidecars, the C-library calls and numerical boundary vectors; replay them | `python3 tools/fixtures/caepipe_mbf_import_vectors.py harvest`, `--check` or `show <id>` | `fixtures/caepipe_mbf/invented/parity/import_vectors.json` rewritten; `--check` writes nothing and exits 1 at the first differing output; `tests/test_caepipe_mbf_import_parity.py` and the crate's `tests/parity.rs` replay it |
| `caepipe_mbf_engine_unicode` | fixtures | Python 3 (standard library) | Derive the Unicode tables the MBF engine crate reproduces Python string behaviour from (`str.isprintable`, `\d` with `int()` values, `str.isspace`) | `python3 tools/fixtures/caepipe_mbf_engine_unicode.py [--check]` | `core/handoff/caepipe_mbf_engine/src/unicode_tables.rs` rewritten; `--check` writes nothing and exits 1 if it differs |
| `deliverables` | coordination | Python 3 | Derive neighbourhood, impact and changed edges from deliverable YAML | Root `python3 -m tools.deliverables --project projects/chirality-piping` | JSON facts; no stored lifecycle |
| `retained_precision_synthetic_bases` | fixtures | Python 3 (standard library) | Regenerate the shared retained-precision corpus's synthetic reader-control bases: derived rows from their own rows by the producer's binary64 sequences, then the corpus rehash rule; producer-solved and hook bases stay with their producer writers | `python3 tools/fixtures/retained_precision_synthetic_bases.py [--check]`, or `tools/fixtures/retained_precision_corpus.py synthetic-bases [--check]` | The corpus (and B2 probe shapes) rewritten in place; `--check` writes nothing and exits 1 at the first difference |
| `run_sheet_authoring` | fixtures | Node (standard library) | Hand-build the run-sheet S1 fixture's sheets, expected batches and expected applied models from DEL-07-02 `Work/run-sheet-entry.md` §3.3 and §6.2, independently of the builder and the applier | `node tools/fixtures/run_sheet_authoring.mjs [--check]` | `fixtures/model_operations/run_sheet_authoring.json` rewritten; `--check` writes nothing and exits 1 if it differs |
| `retained_pricing` | pricing | Python 3 | Price the retained route's memory at a revision (SQ2's TEXT + cap-priced chain under the O-10 rules) and write the registered GENERATED PROFILE block; see its README | `price.py run <rev> --out DIR`; `generate <tree> <retained_memory.rs>`; full clone with basis `2243be380b` | Profile tree, per-point summaries, exit code; the regenerated block |
| `validate_dependencies_schema` | validation | Python 3 | Validate `Dependencies.csv`/`DependencyEdges.csv` v3.1 shape plus canonical enum and row-rule semantics; `--schema-only` is reserved for historical legacy snapshots | CSV path, optional `--schema-only` | VALID/INVALID report and exit code |
