## The rule

This file changes only by copying a later design-system version's `tokens.json` byte for byte. It is never edited by hand. A copy is followed, in the same change, by:

1. the new SHA-256 and versions in the table above and in `tokens.test.ts` (`RECORDED_SHA256`);
2. `npm run tokens` from `apps/desktop`, which regenerates `src/tokens.css`, and the regenerated file checked in.

`src/tokens.css` is generated by `scripts/generate-tokens.mjs` and is not edited by hand either. The generator carries `cssFrom` from the design system's `tools/gen.mjs`: the same variable naming and the same three theme blocks. `tokens.test.ts` fails when `tokens.json` does not have the recorded hash or when `src/tokens.css` is not the generator's output.
