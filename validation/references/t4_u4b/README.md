# T4-U4b references: arc stress quantities

Frozen, independently derived expectations for T4-U4b, which publishes the arc
stress quantities that T4-U4a withheld
([DEL-04-07 Design, arc-frames-and-signs.md](../../../execution/PKG-04/DEL-04-07/Design/arc-frames-and-signs.md)
§9). They land with T4-U5b on model 0.6.0 under `pressure-2` and
`preview-physics-2`, which are not yet defined, so these references are
request-agnostic (see "Binding"). Nothing here is generated by the product. The
generator imports, reads and runs no product code or output.

**Status.** Frozen before any U4b product code. Refuted on 2026-10-17 by a separate TASK that shares no code with the generator, using independent statics, an independent Saint-Venant boundary-value solve and independently certified maxima; every derivation and value was confirmed (worst 4.4e-31 tolerances). Its 8 MINOR findings were repaired, and a second separate TASK confirmed every repair and refuted the new case U4B-RISE74-P-REV (worst 3.9e-31 tolerances; all 49 certifications reproduced). Its missing straight location band was repaired additively. A focused independent check confirmed that addition but refuted the finite-distance meaning of the point-curvature bands, including inherited arc bands. The correction below replaces every affected band using the global lower-curvature bound. A fresh separate TASK independently confirmed all 22 primary bands and five inherited headlines, the global bound and nine edge controls, with no unresolved finding. Maximum and stress values do not change. These references do not establish acceptance.

**Consumer.** T4-U4b, not yet implemented. No product test consumes these
files yet; the U4b implementation binds them as "Binding" describes.

Standard claim fence applies (F-PIP-2; claims taxonomy per DEC-081).

| `SHA256SUMS` | Hashes of the four files above |

Every value is `[decimal with 40 significant digits, binary64]`, in SI units.

**Exact zeros.** `"0"` is an exact zero, written by one of two rules:
- **Known exactly.** Fibre coordinates are formed from the defining vector,
  (y, z) = r (a, b)/hypot(a, b). A component that is exactly zero, such as
  M_y on a planar arc, therefore stays exactly zero.
- **Residue snap.** Any other written value below 1e-60 in SI units is an
  arithmetic residue of the 90-digit working precision (about 1e-90). It is
  written as `"0"`. In this set only components of the derived frame and centre
  vectors are snapped (28 values).

The generator asserts both sides of the snap:
- no written nonzero value is below 1e-30, 30 orders above the snap;
- every snapped value falls below 1e-80 when the cases are recomputed at 110
  digits, so it shrinks with the precision. The largest is 1e-109.

**Precision recheck.** Each check run recomputes every case at 110 digits. All
13,936 written values of the derived geometry, zero scales, quantities and N_w
zeros are unchanged, and every exact zero is exactly zero at both precisions.
The 12 values that the location-band repair added are compared the same way and
counted separately (`values_compared_added_by_the_location_band_repair`).

## Location-band correction (2026-10-17)

The earlier radius √(2 tolerance/|f″(x*)|) used curvature at one point. It
did not prove its stated finite-distance guarantee: independent exact statics
gave losses at the positive edge of 1.000009126887721 tolerances on RISE74/S1
nominal, 1.000009201456984 reduced, and 1.000000074106978 on ARC90-OOP/preview.
The corresponding headlines inherited the same issue. These counterexamples
concern location tolerances; no maximum, stress, resultant or maximum location
is changed to repair them.

Each interior band now uses the existing **global** lower-curvature bound
f″ ≥ −K, derived in item 4 below over the whole member. Since
g(x) = f(x) + Kx²/2 is convex, a supporting slope s at c gives
f(c+d) ≥ f(c) + s d − Kd²/2. At an exact stationary maximum s = 0, so the
loss is at most Kd²/2. The supremum proof includes upward kinks of |N_eff|
and the moment norm; it requires no unchanged branch along the band. A
semiconvex nonsmooth local maximum has both one-sided slopes zero.

The generator uses 99% of the tolerance, with radius solving
Eδ + Kδ²/2 = 0.99 tolerance, where E bounds the supporting-slope residual
at the serialized centre. It uses unrounded K, checks both 40-digit and
binary64 centres, values and radii, and checks both arc coordinates after
conversion by φ. The remaining margin must cover value/centre serialization
and radius rounding explicitly. For an exactly stationary centre this is
√(2·0.99·tolerance/K). Only comparison locations in the member domain count:
[0, φ] in arc radians or [0, 1] in fraction, intersected with the band.

End maxima retain their exact end labels and have no band. K = 0 is handled
without division: a convex function with an interior global maximum is
constant, so with zero supporting slope the full member domain is safe.
Zero point curvature with positive global K remains defined. Check mode
exercises domain clipping, zero and degenerate curvature, an upward kink
inside a band, and endpoint refusal. For every published band it also checks
the lower-bound inequality and direct losses at both clipped endpoints and
three interior locations. The proof supplies the full-interval guarantee;
these direct evaluations check its implementation. Headlines inherit the
corrected member bands with the same value tolerance.

Independent confirmation reproduced every radius within 3.93e-40 relative.
Both sides were checked with 40-digit and binary64 centres/radii and both arc
coordinates. The repaired positive-edge losses are 0.783380209 tolerances
(RISE74/S1 nominal), 0.783343540 (reduced) and 0.320181217 (ARC90-OOP/preview).
The first is the worst exact loss across all bands. The worst conservative
bound against the frozen value is 0.990000079 tolerances. Including the
existing maximum-certification allowance, rounded outward from its reported
precision, the bound against the true maximum is 0.999827500000001 tolerances.
All 27 primary endpoint maxima remain exact and have no band. The oracle diff
changes 130 leaves: only bands and three related descriptions, with no added
or removed leaves; cases and all unrelated values are unchanged. The earlier
broad refutations remain applicable.

## The two selected idealizations

Selection is not qualification. Each definition below is stated with what
qualifies it and what it neglects.

### 1. `bore_load_transferred_toroidal_membrane_v1` (toroidal hoop and radial values)

**Definition.** `toroidal_membrane_hoop` at section angle β is the area average
of the hoop stress over the wall cut at β, that is, the cut force divided by the
cut area. β is measured from +y (toward the bend centre) toward +z:
- the intrados is at 0°;
- the crowns are at ±90°;
- the extrados is at 180°.

The value comes from exact equilibrium of the pressure on the bore, transferred
to that cut. The arc is idealized as a complete torus in an axisymmetric
membrane state. It assumes:
- no transverse-shear resultant on the cuts;
- no end or tangent-junction effects;
- reference geometry and small strain;
- internal pressure p (signed), with zero external pressure.

**Ruling (a).** On each basis b the bore is that basis's own bore r_i,b, with
wall t_b and r_o = D/2. The nominal basis uses r_i,n.

**Derivation.** A point at section radius ρ and angle β lies at distance
ϖ = R − ρ cos β from the bend axis and at height h = ρ sin β along it. Take the
full ring of wall between the cut at β and the crown cut at 90°. Resolve forces
along the bend axis, per radian of revolution:

- **Bore pressure.** The ring's bore carries
  `∫_β^{π/2} p r_i sin β' (R − r_i cos β') dβ' = (p/2) r_i cos β (2R − r_i cos β)`.
  This is p times the projected annulus between ϖ = R − r_i cos β and R.
- **Crown cut.** Its normal lies in the bend plane, so it adds nothing along
  the axis. The idealization neglects its transverse-shear resultant.
- **Cut at β.** Its area is `∫_{r_i}^{r_o} (R − ρ cos β) dρ = t (R − r_m cos β)`,
  with r_m = (r_i + r_o)/2. Its outward normal −e_β has axial component
  −cos β.

Equilibrium gives:

```
sigma_h(beta) = (p r_i,b / t_b) (2R - r_i,b cos beta) / (2R - (r_i,b + r_o) cos beta)
```

The crown value follows by continuity. The free body from the −z crown to β
gives the same expression. Equilibrium fixes only ∫σ ϖ dρ, so the area average
is the determined quantity. A plain thickness average is not fixed by
equilibrium; it coincides with the area average at the crowns and in the
thin-wall limit.

**Properties, all checked.**
- At the crowns, σ_h = p r_i,b/t_b, the straight Lamé wall mean.
- As R → ∞, σ_h tends to that mean at every β.
- In the thin-wall limit it reduces to the classical (p r/2t)(2R − r cos β)/(R − r cos β).
- It is monotone in cos β (dσ/d cos β ∝ 2R r_o p). So for p > 0 the intrados exceeds the crown, which exceeds the extrados; p < 0 reverses this.
- Domain: R > r_o, so the torus does not self-intersect. The expression stays finite for R > r_m.

**`radial_surface`.** The radial stress is −p at the basis's bore and 0 at the
outer surface.

**Named alternate, reading (b).** This variant is information and a
discriminator only. It loads the nominal wall with the D-5 pressure bore r_i,r:

```
p r_i,r (2R - r_i,r cos beta) / (t_n (2R - (r_i,n + r_o) cos beta))
```

It is not the reference because its crown, p r_i,r/t_n, differs from the
straight nominal Lamé mean p r_i,n/t_n. So arcs and straights would disagree at
the crown on the nominal basis. On U4B-L90-P the difference is 2.18e7
tolerances: 53.342 MPa against 52.048 MPa.

**What qualifies it.**
- The derivation above.
- An independent 3D quadrature on all 12 arc/basis pairs. Each pressure-force
  element is p (∂P/∂β' × ∂P/∂θ) over the bore patch, integrated with
  Gauss–Legendre in β' and θ. The cut area vector is integrated over ρ and θ.
  Both free bodies were used, at β = 0, 30, 60, 80, 100, 135 and 180°. Worst
  relative difference from the closed form: 6.8e-89.
- The crown against a quadrature of the Lamé field: 7.7e-50.
- The straight limit at R = 1e40: 6.3e-42.
- The thin-wall limit at t = 1e-30 r_o: 1.5e-30, of order t/r.
- The ordering check.
- The refutation of 2026-10-17, and the second TASK's refutation of the new case (see Status).

**What it neglects.**
- Ovalization and the hoop bending that in-plane and out-of-plane moments cause in a bend.
- Bending boundary layers, including the crown region of a thin torus.
- Tangent-end and junction effects, where the arc is not a complete torus.
- The through-thickness hoop distribution; only the cut average is given.
- Transverse-shear resultants on the cuts.
- Pressure stiffening.
- Any hoop from external loads.

### 2. `local_straight_annulus_on_arc` (Saint-Venant transverse shear)

**Definition.** `sv_transverse_shear` uses the Saint-Venant flexure field of
the homogeneous straight annulus of each basis (SHEAR_REFERENCE refutation §2).
The tangent-frame V_y and V_z of each section drive it by superposition, with
no curvature correction. On straights the same field applies, and there it is
exact within Saint-Venant theory.

The field in polar form uses C = 1/(2(1+ν) I_b), c = (3+2ν)/4, and
(y, z) = r (cos β, sin β):

```
tau_r    = -C c (r^2 - r_o^2)(r^2 - r_i^2)/r^2 (V . e_r)
tau_beta =  C g(r) (V . e_beta),   g(r) = c (r_o^2 + r_i^2 + r_o^2 r_i^2 / r^2) - (1 - 2nu) r^2 / 4
```

The generator checks that this polar form equals the refutation's Cartesian
form to 2.9e-89. The components are the tractions τ_xy and τ_xz on the +x
(j-side) face. They are frozen at six fibres (0, 45, 90, 135, 180 and 270°)
on both surfaces.

**Maximum (derived here).**

```
tau_max = |V| ((3+2nu) r_o^2 + (1+2nu) r_i^2) / (4 (1+nu) I_b)
```

It lies on the inner surface at the two fibres normal to V, at
β = atan2(V_y, −V_z) and atan2(−V_y, V_z), and it is directed along V. The two
fibres are an unordered pair: the oracle lists them by ascending β, and a
consumer matches them as a set. When V = 0 every fibre ties.

Proof. Write B0 = −c s + r²/2 and B2 = c r_o² r_i²/r² + e r², with
s = r_o² + r_i² and e = (1+2ν)/4. Then:
- At radius r, |τ|² = C²|V|²(B0² + B2² + 2 B0 B2 cos 2α), so the largest
  value over α is C|V|(|B0| + |B2|).
- |B0| + |B2| equals the larger of |B0 + B2| and g = B2 − B0.
- |B0 + B2| = c (r_o² − r²)(r² − r_i²)/r², which is at most c (r_o − r_i)².
- g decreases strictly in r. Its largest absolute value is
  g(r_i) = ((3+2ν) r_o² + (1+2ν) r_i²)/2.
- g(r_i) exceeds c (r_o − r_i)² whenever ν > −1.
- At r_i, B0 < 0 < B2, so the maximum over α lies at α = ±90° only.

**Domain.** The result holds for every isotropic −1 < ν < 1/2 with
0 < r_i < r_o. A sampled scan over ν ∈ {−0.95, −0.8, −0.6} and
r_i/r_o ∈ {0.1, 0.5, 0.9} agrees exactly.

**Limits.**
- Thin wall: 2V/A.
- Small hole: twice the solid-circle centre value (3+2ν)/(2(1+ν)) V/A. This
  is the small-hole factor 2.
- ν = 0: |V|(3r_o² + r_i²)/(4I).

The value divided by V/A is ((3+2ν) + (1+2ν)m²)/((1+ν)(1+m²)), with
m = r_i/r_o. At m ≥ 0.5 and ν ∈ {0, 0.27, 0.3} it differs from 1, 1/κ_E, 2,
the solid-circle values and 4/3. For example, at m = 0.8 and ν = 0.27 it is
2.1728, against 1/κ_E = 1.9602. It equals 2V/A and V/(κ_E A) only in the
thin-wall limit.

**What qualifies it.** The derivation, plus checks on each of the 10 distinct
case annuli:
- With trapezoid quadrature in β and Gauss–Legendre in ln r, ∫τ dA = V, the
  transverse resultant is zero and the torque is zero (1.3e-88).
- The shear energy equals 1/(κ_E A) with SHEAR_REFERENCE's κ_E (1.3e-88).
- The radial shear vanishes at both surfaces (1.1e-89).
- Equilibrium holds: div τ = −(V_y y + V_z z)/I, by central differences
  (2.2e-47).
- Beltrami–Michell compatibility holds: the Laplacian of the component along V
  is −V/((1+ν)I) and of the other component 0 (3.5e-41). This is what fixes
  the ν-dependence.
- A 25 × 360 dense grid confirms the maximum's value (to 1e-60) and its
  location (inner radius, ±90° from V).
- The limits above hold.
- The refutation of 2026-10-17, and the second TASK's refutation of the new case (see Status).

**What it neglects.**
- Curvature correction of the shear field (the curved-beam distribution).
- Ovalization.
- The T/R coupling in dM_y/ds, which the straight field does not see.
- End and junction effects.
- Torsional shear is a separate quantity (`torsional_shear` = T r_o/J_b,
  signed). `flexure_plus_torsion_check` adds the torsion field (−T z/J_b,
  T y/J_b) at the four outer named fibres as a separately named check.
- The field depends on ν, and each case uses its material's ν. Five of the
  six materials have ν ≠ 0.3 (0.27, 0.31, 0.29, 0.26, 0.28).

### The gap

No vetted basis quantifies either idealization's error against shell or
curved-beam theory. That includes:
- ovalization (the Kármán and Brazier mechanisms);
- bending boundary layers;
- tangent-end effects;
- curvature correction of the shear field.

The rest of this subsection is *inference*, not a qualified bound:
- For thin, tight bends under bending, ovalization-induced hoop bending stresses
  may be of the order of the nominal bending stress or larger. Neither
  idealization represents them.
- The curvature correction to the shear field is plausibly of relative order
  r_o/R. That is not small on the tight case here (R/r_o = 1.5).

These references qualify each definition only as the stated idealization.

## Other §9 quantities

3. **Signed fibre normal stresses** (`fibre_normal`, `normal_extremes`).
   - σ_x = N_eff/A_b + M_y z/I_b − M_z y/I_b (STRESS_REFERENCE §1), where
     N_eff = N_w on pressurized members of the exact route and N otherwise.
   - They are frozen at the four named fibres on both surfaces, per station and
     basis.
   - σ⁺ and σ⁻ are N_eff/A_b ± hypot(M_y, M_z)/Z_b at (y, z) = ±r_o(−M_z, M_y)/hypot.
   - A fibre's compared quantities are its (y, z), formed from that vector.
     Its `beta_deg` is informational, in (−180, 180], and exactly 0, 90, 180 or
     −90 on an axis. So a fibre on the −y axis is +180. ARC106 (M_y = 0) and
     OOP-PREVIEW's end_j exercise this.
   - When bending is zero the fibres are recorded as tied. ARC106's end_j
     exercises this.
4. **Arc maximum** (`member_maximum`, `headline`).
   - Covers `pipe_elastic_normal_stress_maximum_v2` and the preview maximum.
   - The value is the maximum over the whole member of |N_eff|/A_b + hypot(M_y, M_z)/Z_b.
   - The resultants are closed forms on the {1, cos ψ, sin ψ, ψ cos ψ, ψ sin ψ, ψ} basis of plan 01:
     - F(ψ) = F_beyond + w R Δψ;
     - M(ψ) = M_beyond + (Q − r(ψ)) × F_beyond + R (∫r dψ − r(ψ) Δψ) × w;
     - ∫r dψ = c Δψ − R (e_x(ψ₂) − e_x(ψ₁)).
   - The exact derivatives follow from dF/ds = −w, dM/ds = −e_x × F, de_x/ds = e_y/R and de_y/ds = −e_x/R:
     - dN/dψ = −R w·e_x + V_y;
     - dM_y/dψ = R V_z − T;
     - dM_z/dψ = −R V_y.
   - **Analytic extremum.** The candidates are both ends and every interior
     root of f′ that changes sign from + to − on a 4,096-cell grid, refined by
     bisection to the working precision. At the kinks of |N_eff| and of the
     hypot, f′ jumps upward, so a kink is never a maximum.
   - **Dense-sampling bracket.** The bracket is [max of 4,097 samples, that
     maximum + L h/2]. The Lipschitz bound is rigorous:
     - L = (R|w| + F_max)/A_b + (R F_max + M_max)/Z_b;
     - F_max = |F(0)| + |w| R φ;
     - M_max = |M(0)| + R φ F_max.
   - **The bracket's role.** It is a coarse consistency check. Its width is
     5.3e-5 to 9.3e-4 of the value, about 5e4 to 9e5 tolerances. So lying
     inside it does not certify the maximum at the criterion: two roots of f′
     in one grid cell could hide a higher peak.
   - **Certification at the criterion.** Every frozen maximum (arc, straight
     and intensified, 49 in all) is certified by a rigorous upper bound.
     - Both measures are sums of suprema of linear functionals: |N_eff|,
       hypot(M_y, M_z) and hypot(i_op M_y, i_ip M_z). So f″ ≥ −K holds in the
       distributional sense, with the kinks of |·| and of the hypot included.
     - On a cell of width h, max f ≤ max(endpoint values) + K h²/8.
     - K comes from the closed-form second derivatives: N″ = −2R w_y − N,
       M_y″ = −R² w_z − M_y and M_z″ = R² w_y + R N. Here N is the
       pressure-free statics force (S on pressurized arcs), and N_eff″ = N″
       because pA_i is constant along the member. Hence
       K = (2R|w| + F_max)/A_b + (R²|w| + M_max + R F_max)/Z_b, and
       max(i_ip, i_op) (R²|w| + M_max + R F_max)/Z_b for the intensified
       measure.
     - On a straight, K = 2 hypot(b₂, c₂) exactly, from the quadratic
       coefficients of M_y/Z and M_z/Z in the fraction.
     - Starting from the 4,096-cell grid, cells whose bound exceeds the value
       + 0.01 tolerance are bisected until every cell closes. No sample
       exceeds the frozen value, which is attained at the frozen location.
     - The true maximum is therefore within 0.01 tolerance of the frozen value.
       The worst bound is 0.0098 tolerance, after 534 bisections in all.
     - The second-derivative formulas are checked against central differences
       of the exact first derivatives (1.3e-51).
   - Each member or intensified maximum record, arc or straight, gives:
     - the value and method;
     - the location: its kind (`end_i`, `end_j` or `interior`) and fraction,
       plus ψ* on arcs (`psi_rad`, and `psi_deg` when interior);
     - the governing fibre (not applicable on intensified records);
     - the resultants at the maximum (N_eff, M_y and M_z);
     - on interior maxima only, a `location_band` within which the value
       stays inside the criterion on the member domain, from the global
       f″ ≥ −K bound and the 99% budget described above, in ψ and fraction
       on arcs and in fraction on straights. The pointwise f″ remains a diagnostic
       (`second_derivative_per_rad2` on arcs, `second_derivative_per_fraction2`
       on straights), not the band's bound. End maxima, arc or straight, are exact and carry no band;
     - the bracket;
     - the certification (K, bisections, finest cell, bound above the value in tolerances);
     - the station-only maximum, its shortfall in tolerances, and whether the
       stations miss the peak by more than one tolerance
       (`interior_peak_missed_by_stations`);
     - on arc member maxima, the quadratic-method mutant value (`mutant_values`).
   - Straight members use the STRESS_REFERENCE §6 polynomial method on exact
     statics polynomials, with the same bracket and certification. RISE74's S1
     exercises an interior straight maximum. Its f″ in the fraction is exact
     from the polynomials and agrees with a central second difference to
     4.3e-41.
   - The headline is the maximum over members, per basis, with its member,
     co-governing members, location and governing fibre. An interior headline
     also carries its member's `location_band`; the tolerance is the same,
     because the value is at least every station value of the case.
   - On ARC106 the closed form is ψ* = φ − π/2 = 2 atan(4/3) − π/2 (fraction
     0.15302), with f* = |p|A_i/A_b + F(1/A_b + R/Z_b). The general method
     reproduces it to 3.6e-56.
5. **Directional-SIF intensified bending** (`intensified_bending`, `intensified_bending_maximum`).
   - On arcs, M_z is in-plane and M_y out-of-plane. The measure is hypot(i_ip M_z, i_op M_y)/Z_b, per station and basis.
   - `intensified_bending_maximum` is the along-arc maximum of this pure

   - Nothing is combined with it. No factor multiplies N/A, the membrane stress, torsion or the max-normal scalar.
   - I1 is reproduced exactly: 6√5 MPa and 2 + 6√5 MPa.
   - **Markers.** No vetted basis says which axis is in-plane at a geometry-only bend or branch marker at a straight end. Only the component-frame I1 control is frozen (`markers`).
6. **Algebra classes** (`algebra_classes_informational`). This is information
   only, by STRESS_REFERENCE §5:
   - Signed linear quantities combine only as matching signed quantities: same
     frame, station, fibre and basis.
   - Maxima and intensified measures are recomputed or enveloped. They are
     never combined.

## Statics of the cases

**Why the values are pure statics.** Every line is statically determinate:
one full anchor, a chain of members with tangent junctions, and a free tip. So
every section action is the resultant of the loads beyond the cut, and every
frozen value is independent of:
- arc stiffness, k and the shear model;
- beam theory and the solver;
- E and α.

The flexibility factor k is invented and irrelevant. The shear model is stated
in each case, and the values are identical under both models. Realized arcs
are Euler–Bernoulli in either case.

**N_w = S + pA_i.** Every pressurized line has a whole-line region and
closures transferring to the wall at both ends. Take the free body of the
wall, the fluid beyond the cut and the transferring tip cap. Its external
forces are:
- the applied loads;
- the anchor-side fluid pushing on the cut fluid face with pA_i, along the
  direction toward the tip, through the bore centre (the section centroid).

The cap is internal to this free body. Hence N_w = S + pA_i, while V and M are
unchanged. Pressure adds no shear and no bending moment, whatever the arc's
shape.

This is checked on every station of every pressurized case with the wall-only
free body: the arc wall line load −pA_i e_y/R, by quadrature, plus the tip
cap. The residual is at most 2.6e-89 relative. On the moved copy it is
1.6e-13, from the about 1e-16 rad kinks that binary64 rounding leaves.

**Number conventions** (as in U4a).
- Exact binary64: node positions, y_reference and load components.
- Exact decimal targets: section, material, R, p, k and SIF values.

## Oracle layout

The oracle is in `oracle.json` under `cases.<id>`.

**`derived`**, per member:
- geometry, including the arc's R, s, c, φ, centre, normal and R/r_o;
- `bend_angle_binary64_for_authoring`;
- the section bases;
- the pressure bore and pA_i;
- the tangent frames at the stations.

**`quantities`**, keyed by agnostic name, then member, then station, then basis:
- `resultants_tangent_frame_j_side`: N, or S and N_w, plus V_y, V_z, T, M_y and M_z;
- `fibre_normal` (`outer`/`inner`, then fibre);
- `normal_extremes`;
- `sv_transverse_shear_max` (value, surface and both fibres);
- `sv_transverse_shear` (`outer`/`inner`, then fibre, then τ_xy and τ_xz);
- `torsional_shear`;
- `flexure_plus_torsion_check`;
- `intensified_bending` and `axial_plus_intensified_bending`;
- `toroidal_membrane_hoop` and `radial_surface` (per arc and basis, station-independent);
- `member_maximum` and `intensified_bending_maximum` (per member and basis, each with its `certification`);
- `headline` (per basis).

The rest of the case record holds `zero_scales`, the `discriminators`, and, on
arcs where it occurs, `effective_axial_force_zeros_on_arcs`. At the top level
are the conventions, definitions, criterion, `discriminator_summary`,
`markers`, the algebra classes and `cross_checks`. Per mutant,
`discriminator_summary` separates `discriminable_in`, `not_discriminable_in`
(formed, but no row moves by 1e3 tolerances) and `not_formed_in` (the case has
no row the mutant applies to).

## Criterion

A row passes when |obs − exp| ≤ 1e-9·max(|exp|, zero_scale), in both solver
modes.

**Zero scales:**
- **force:** per member, the largest |N or S|, |V_y| or |V_z| over the five cuts;
- **moment:** per member, the largest |T|, |M_y| or |M_z|;
- **normal_stress:** per member and basis, the largest station max_abs_normal (fibre, extremes, maxima and intensified rows);
- **shear_stress:** per member and basis, the largest station SV max + |torsional shear| (all shear rows);
- **pressure_stress:** per arc and basis, the larger of |p| and the largest |hoop| (hoop and radial rows);
- **headline:** the case's largest station max_abs_normal for that basis.

When a scale is zero, the fallback is the case's scale. The oracle's
`criterion` block states these fallbacks.

**Locations.**
- An interior ψ (arcs) or fraction (straights) is compared within its
  `location_band`; end maxima are exact and carry no band. An interior
  headline carries its member's band. The oracle's `criterion` block states
  this as `location_bands`.
- Fibre coordinates (y, z) are compared at the criterion, with zero scale r_o.
  `beta_deg` is informational and is not compared.
- The two `sv_transverse_shear_max` fibres are an unordered pair, matched as a set.

**Units.** Compare a product's MPa or mm after exact conversion.

**How each mutant is formed.** The station rows are per member, station and
basis. The hoop rows are per arc, basis and fibre. The maxima are per member
and basis, plus the headline.
- `fibre_mz_y_sign_flipped`: `fibre_normal` = N_eff/A_b + (M_y z + M_z y)/I_b, the sign of the M_z·y term flipped.
- `fibre_frame_rotated_y_away_from_centre`: `fibre_normal` = N_eff/A_b − (M_y z − M_z y)/I_b, with y and z reversed together.
- `fibre_component_abs_sum`: `max_abs_normal` = |N_eff|/A_b + (|M_y| + |M_z|)/Z_b, and `sigma_plus` = N_eff/A_b + (|M_y| + |M_z|)/Z_b.
- `sv_v_over_a`, `sv_two_v_over_a`, `sv_solid_circle_four_thirds`: the SV maximum = |V|/A_b, 2|V|/A_b and 4|V|/(3A_b).
- `sv_v_over_kappa_a`: the SV maximum = |V|/(κ_E A_b), with SHEAR_REFERENCE's κ_E for that basis's annulus and ν.
- `sv_solid_circle_centre`: the SV maximum = (3+2ν)/(2(1+ν)) |V|/A_b.
- `sv_max_at_outer_surface`: the SV maximum = the field at the outer surface normal to V, |V|((1+2ν) r_o² + (3+2ν) r_i²)/(4(1+ν) I_b).
- `sv_max_on_axis_parallel_to_v`: the SV maximum = |V|(3+2ν)(r_o − r_i)²/(8(1+ν) I_b), the bound on the axis parallel to V.
- `sv_vy_vz_swapped`: the SV field components with V_y and V_z interchanged.
- `sv_nu_fixed_0_3`: the SV maximum and components with ν = 0.3 in place of the material's ν. It is not formed where ν = 0.3.
- `sif_factors_swapped`: `intensified_bending` = hypot(i_op M_z, i_ip M_y)/Z_b, and its along-arc maximum.
- `sif_one_scalar_for_both_directions`: `intensified_bending` = max(i_ip, i_op) hypot(M_y, M_z)/Z_b. Its maximum is max(i_ip, i_op) times the along-arc maximum of hypot(M_y, M_z)/Z_b.
- `sif_applied_to_whole_max_normal`: `axial_plus_intensified_bending` = i_ip (|N_eff|/A_b + hypot(M_y, M_z)/Z_b), using i_ip only.
- `sif_applied_to_axial`: `axial_plus_intensified_bending` = i_ip |N_eff|/A_b + `intensified_bending`, using i_ip only.
- `sif_applied_to_torsion`: `torsional_shear` = i_ip T r_o/J_b, using i_ip only.
- `k_multiplying_stress`, on arcs only:
  - the bending term of `fibre_normal` times k;
  - `max_abs_normal` = |N_eff|/A_b + k hypot(M_y, M_z)/Z_b;
  - on the intensified rows, both SIFs replaced by k: `intensified_bending` = k hypot(M_y, M_z)/Z_b, and its maximum is k times the along-arc maximum of hypot(M_y, M_z)/Z_b;
  - `member_maximum` = the along-arc maximum of |N_eff|/A_b + k hypot(M_y, M_z)/Z_b.
- `rows_other_basis_section`: every row of one basis is given the other basis's value. This covers station rows, hoop, maxima and headline, on the exact route only.
- `hoop_straight_lame_inner` / `_outer`: the straight Lamé hoop p r_i²(1 + r_o²/r²)/(r_o² − r_i²) at r = r_i and at r = r_o.
- `hoop_classical_mid_radius_thin`: (p r_m/(2t))(2R − r_m cos β)/(R − r_m cos β).
- `hoop_intrados_extrados_swapped`: the closed form with cos β replaced by −cos β.
- `hoop_variant_b_pressure_bore_on_nominal_wall`: variant (b) on the nominal basis. It is formed only where r_i,r ≠ r_i,n.
- `radial_sign_flipped`: the inner `radial_surface` = +p.
- `max_station_only`: each member maximum, intensified maximum and headline replaced by the largest of its five station values.
- `max_quadratic_straight_method_on_arc`: the §6 method applied, on each arc, to the quadratics in the fraction through end_i, midspan and end_j of N_eff/A_b, M_y/Z_b and M_z/Z_b. That is, N_eff, M_y and M_z are interpolated quadratically through those three stations.
- `max_abs_sum_objective`: the along-member maximum of |N_eff|/A_b + |M_y|/Z_b + |M_z|/Z_b.

The along-arc maxima of the wrong measures come from 4,097 samples and a
golden-section refinement around the best sample. On straights, the abs-sum
uses 4,097 samples. This accuracy is ample for the 1e3-tolerance listing.

Notes on the mutants:
- The M_z·y sign flip and a y axis mirrored away from the centre give identical
  fibre values. Each equals the mirror-image fibre. The rotated-frame form
  reverses y and z together.
- `max_station_only` is weakest on L90's arc, whose peak lies near quarter_3.
  ARC106 separates it by 1.55e7 tolerances, and the quadratic method there by
  1.9e7.

## Inferred conventions (confirm with the U4b design and consumer)

1. A uniform member load on an arc is a constant global force per unit arc
   length. U4a's frozen reference is reproduced only under this reading; no
   0.6.0 definition was available.
2. `toroidal_membrane_hoop` and `radial_surface` are station-independent. They
   are keyed per arc, basis and fibre. A per-station row kind repeats them at
   the five stations.
3. Fibre names map to β as follows: on arcs y_pos is the intrados and y_neg
   the extrados; on straights the names refer to the local axes. The SV
   components are tractions on the +x (j-side) face in the frame at the
   section.
4. The preview route's single section is keyed `preview_single_section`
   (t − c_m).
5. `axial_plus_intensified_bending` uses |N_eff|: N_w on pressurized exact
   members. I1 itself has no pressure.
6. The SIF inputs are named `i_ip` (on M_z) and `i_op` (on M_y) in the arc's
   tangent frame. The 0.6.0 field names are not defined.
7. A maximum's location is ψ from authored i with fraction ψ/φ on arcs, and u
   on straights.
8. The anchor-end closure transfers to the wall. It affects only the anchor
   reaction, which is not frozen.

## Not covered, and why

- **Statically indeterminate lines.** Their resultants depend on k, the shear
  model and the solver. These references check the U4b recovery from
  determinate resultants. Indeterminate behaviour is U4a's and the solver
  references' scope.
- **Markers.** There is no vetted in-plane axis; see `markers`.
- **Directional k.** This is a deferred unit.
- **Other pressure configurations.** Partial regions, separately supported
  closures, kinks and mitres, and external pressure as a separate input are
  not covered.
- **An exact-route arc outside every pressure region.** No case has one.
  Whether its `toroidal_membrane_hoop` and `radial_surface` rows are published
  at p = 0 or omitted is for the U4b design to decide. The formulas are linear
  in p, so published rows would be zero.
- **Thermal and self-weight loads.** None are applied.
- **Hoop from bending, ovalization and through-thickness distribution.** See
  "The gap".
- **Product row kinds and request hashes.** These wait for 0.6.0.

## Binding when model 0.6.0 is defined

1. A builder authors one product request per case from `cases.json`: bend
   components with R, the bend angle and k, primitive loads per global
   component, the pressure region and its terminals, the shear model and the
   SIF fields.
   - **Builder rule for bends.** Each realized arc becomes one bend component
     that references the arc's pipe. It is attached at
     `arc.bend_component_attachment_node`, the arc's authored from node, as U4a
     attaches all 28 of its bend components. It states:
     - `bend_radius` R;
     - the bend angle `arc.bend_angle_binary64_for_authoring`, the binary64
       nearest to the included angle formed from the chord and R;
     - the user k and the SIF values.
   - The generator asserts that the stated angle equals its own geometry and
     that the attachment node is the from node.
2. The U4b design's row-kind table maps the agnostic quantity keys to row kinds.
3. Oracle values never move to match a product.
4. Request SHA-256 values are added to the oracle once the requests exist.
   Adding them changes only those bindings and the files' hashes.

## Reproduce and change

```
python3 -I -B generators/u4b_reference.py          # check: rebuild, compare byte for byte, run every cross-check (about 15 s)
python3 -I -B generators/u4b_reference.py --write  # intentional changes only
shasum -a 256 -c SHA256SUMS
```

Check mode also fails on any unexpected or missing file.

**Re-freeze rules.**
- No value changes to match a product output. A disagreement goes back to this
  reference's owner and its refuter.
- Changing either definition or its reading is a re-freeze with a recorded
  reason and a new refutation. That includes the cut average, ruling (a) and
  the SV superposition.
- Changing a row convention (a key, unit, sign or fibre) re-derives the rows.
  Physical values stay unless the convention changes their meaning.
- Re-authoring the requests changes only their hashes, never oracle values.
- If the U4a files change, the generator refuses until the change is examined.
