# RT-A4 references: absolute-sum and SRSS kernel table

Frozen, independently derived expectations for the unsigned load-case algebra
kernel (RT-A4, slice K): the V-1 table of DEL-05-02 Work
[`absolute-sum-srss-combinations.md`](../../../execution/PKG-05/DEL-05-02/Work/absolute-sum-srss-combinations.md)
§7, for the definitions of §3. Each row lists binary64 factors and values and
the expected bits of the absolute sum A and the SRSS R, or the refusal
`non_representable`. The table is read and checked bit for bit by
[`core/loads/load_case_algebra/src/unsigned_tests.rs`](../../../core/loads/load_case_algebra/src/unsigned_tests.rs).

Nothing here is generated by the product. The generator uses the Python
standard library only and imports, reads and runs no product code; it reads
only the committed files of this directory, to hash them. All values are
invented. Standard claim fence applies (F-PIP-2; claims taxonomy per DEC-081).

Status: candidate references, derived and cross-checked by their author TASK.
They have not yet been independently refuted.

## Definitions

For factors fᵢ and values xᵢ (finite binary64), with RN rounding to nearest,
ties to even, at the binary64 quantum of the result's binade (2⁻¹⁰⁷⁴ in the
subnormal binade):

- A = RN(Σ |fᵢ·xᵢ|), the exact sum rounded once;
- zᵢ = RN(fᵢ·xᵢ) and R = RN(√Σ zᵢ²), the exact sum of squares, its root
  rounded once;
- an exact zero gives +0.0; a value whose exact magnitude is at least
  MAX + 2⁹⁷⁰ rounds beyond the largest finite binary64 and is refused, as is
  an R whose zᵢ is. For R that is S ≥ (MAX + 2⁹⁷⁰)², equality included (the
  tie goes to the even 2¹⁰²⁴).

## Independence

Every value is an exact `fractions.Fraction`. RN is integer rounding of the
exact rational at the quantum of its binade. The root is rounded without a
candidate or a midpoint search, unlike the kernel: with Q the result's
quantum and T = S/Q², n = `math.isqrt(floor(T))` is ⌊√T⌋, and the exact
remainder T − n² against n + 1/4 decides between n and n + 1, ties to even.
The kernel instead steps a floating candidate by exact midpoint signs in the
product's exact accumulator.

Rows whose S must lie at a midpoint, or one accumulator quantum (2⁻²¹⁴⁸)
either side of it or of the overflow threshold, are built by an exact greedy
decomposition of the target S into squares of binary64 values (each the
largest whose square does not exceed what remains), which ends exactly
because every remainder is a whole number of quanta.

## Coverage (§7 V-1)

| Group | Cases |
|---|---|
| zeros and −0.0 | `zero_*` (values and factors of either sign) |
| one term | `one_term*`, from 2⁻¹⁰⁷⁴ to MAX, negative values and factors, a non-dyadic factor |
| opposite signs | `opposite_signs_*` |
| dyadic and non-dyadic factors | `dyadic_factors`, `non_dyadic_*`, `five_terms` (permuted by V-3) |
| subnormal results, R in the subnormal binade | `subnormal_*`, `z_underflows_to_zero`, `z_rounds_up_to_tiny`, `products_below_half_quantum`, `non_dyadic_subnormal`, `span_tiny_to_2p1023` |
| overflow of zᵢ and of R | `z_overflows*`, `a_overflows_r_finite`, `max_and_one` (R = MAX), `max_and_max` (refused) |
| the overflow threshold | `threshold_minus_quantum` (R = MAX), `threshold`, `threshold_plus_quantum` (refused) |
| near-midpoint roots | `midpoint_{even,odd}_{minus_quantum,tie,plus_quantum}`, `pythagorean_tie_*`, `integer_midpoint_minus_one`, `subnormal_near_midpoint_*`, `fold_loses_tail` |
| ties in A | `absolute_sum_tie_even_{down,up}`, `absolute_sum_fold_loses_tail` |
| exact squares | `exact_square_*`, `opposite_signs_3_4`, `subnormal_exact_root` |
| the smallest normal | `smallest_normal_gaps`: 2⁻¹⁰²² − 2⁻¹⁰⁷⁴ and 2⁻¹⁰⁴⁸ give R = 2⁻¹⁰²², where both gaps are 2⁻¹⁰⁷⁴ |

V-2 (agreement with `correct_norm::norm3`), V-3 (order) and V-4 (mutants) are
Rust tests beside the kernel and have no frozen data. V-5 (the closed-form
cantilever) belongs to the wiring slice and is not here.
