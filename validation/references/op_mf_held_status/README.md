# Held-status solve references (`minuend_final`)

Frozen, independently derived expectations for DEL-05-02 Work
[`operating-case.md`](../../../execution/PKG-05/DEL-05-02/Work/operating-case.md) §7.2 and §7.9
(H-1 to H-18, with H-1b, H-6b, H-14r, H-15a/b/c, H-16a/b and H-17c). They are read by the product
tests of the held-status solve.

Nothing here is generated by the product. The generator uses the Python standard library only
(exact `fractions.Fraction`) and reads no product code. All values are invented. Standard claim
fence applies (F-PIP-2; claims taxonomy per DEC-081).

Status: candidate references, derived by their author TASK. The design-time values (§7.9) were
reproduced independently in review (gpt-6-astra, at `ecda16cd2` and `30b6b34e7`). They have not
yet been refuted against the product.

| File | Role |
|---|---|
| `generators/held_status_reference.py` | The generator: an exact rational 2D Euler–Bernoulli frame in the XZ plane, each case's own state found by enumerating every candidate state (exactly one must be admissible), and each held solve classified once by §7.2's rules |
| `references.json` | The expectations: every value as an exact fraction and as its nearest binary64 (`float.hex()`) |
| `SHA256SUMS` | Hashes of the generator and `references.json` |

Run `python3 -I generators/held_status_reference.py` in this directory to rebuild every output in
memory and compare it with the committed file; `--write` rewrites it.

**The models.**
- The bar of V-1: L = 4 m, k = EA/L = 2²⁰ N/m, α = 2⁻¹⁶ /K. The tip-UZ bar adds a UZ base
  restraint at the tip, which is the derived-normal source.
- The V-2 cantilever in units of P = 48, L = 2 and EI = 40, so s\* = 1.
- The L-frame of H-14, with EA = 2²⁴ and EI = 2²⁰. Its coupling g = ∂R_n/∂φ = −24/19 is recorded.
- H-7g: NI `p_tests.rs` `gap_chain(1)` as a product model.

**Each case records:**
- the source's own state;
- the target's own state;
- the target's held solve, with its classified state, the derived-normal branch verdict and
  `released` (a changed state or an inadmissible branch);
- the source minus held differences;
- where §7.9 names one, the mutant the case kills: the frozen source normal, an uncoupled normal,
  or holding the source's displacement.

**Binary64 modelling.** One case depends on how the product rounds, and the generator models it.
- **The rule.** The step forms an explicit-normal friction force fl(−dir·μ·|N|) and applies it only
  when it is nonzero. The classifier selects the zero-limit rule exactly when fl(μ·N) = 0.
- **H-15c.** With μ = 2⁻¹⁰⁷⁴ and N = 1/4 the product underflows, so no force is formed and the
  support is kept sliding.
- **Every other case** has a nonzero or exactly zero exact product, so the rule changes nothing
  there.
