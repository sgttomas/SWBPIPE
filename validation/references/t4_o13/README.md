# O-13 arc recovery guard references (T4-I34)

Frozen, independently derived references for the arc recovery guard
(`execution/PKG-04/DEL-04-01/Design/arc-recovery-guard.md`). Nothing here is
generated by the product.

## Files

| File | Role |
|---|---|
| `o13_candidates.json` | T4-I34's frozen candidates, byte for byte: `stiffness` (the 12×12 global K(z) of 12 arcs), `element_rows` (24 records: held operands, u and the exact chord-frame end actions f(z, u)) and `model_rows` (22 sets of exact published arc rows f* from 120-digit model solves), 40 significant digits |
| `o13_fk_references.py` | writes `o13_fk_references.txt` from `o13_candidates.json` (standard library; `python3 -I o13_fk_references.py` here) |
| `o13_fk_references.txt` | the FK tests' form: each value as three binary64 terms (hex), with the file's relative allowance (1e-39) for the 40-digit rounding |

Consumers: FK `src/structural/arc_recovery_tests.rs` (C1–C6) reads the text
file; PP `src/s11g_tests/arc_recovery.rs` (P1) reads `model_rows` from the JSON.
