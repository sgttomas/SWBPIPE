## How the tests compare

The zero-floor rule R02-Z (`round_02.zero_floor_rule`) governs every FK
unit-level array: an entry passes when |obs − exp| ≤ 1e-12·max(|exp|, F), F
being its family's floor in that evaluation (`round_02.zero_floors`). Families
with F = 0 (`exact_zero_family_list`) are compared exactly. Ranks, PD flags and
the W4 decision are exact. U3-FINITE-ROTATION-NEGATIVE keeps its own
1e-12·L rule.

## Reproduce

Standard-library Python 3 only:

```
python3 -I generators/u3_reference.py <round-01 output json>
python3 -I generators/u3_round02.py <round-01 json> <round-02 output json>
```

The second command reproduces `u3_reference_cases.json` byte for byte.
