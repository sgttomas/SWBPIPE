# Skewed restraints (R-6, R-7): independent references

Frozen, independently derived expectations for skewed translational line stops
and springs: the authored-direction policy, the canonical division-free basis,
constraint rank and reaction attribution, transformed loads and reactions,
imposed motion along a skewed restraint, and the named refusals. The build
design is DEL-04-03 Work
[`skew-restraints.md`](../../../execution/PKG-04/DEL-04-03/Work/skew-restraints.md);
the adopted kernel design is DEL-05-02 Work
[`operating-case.md`](../../../execution/PKG-05/DEL-05-02/Work/operating-case.md)
§2.2–§2.6 (R-6, R-7).

Nothing here is generated by the product. The generator imports, reads and
runs no product code. All model data are invented. No equation, value or
example from the `domains/piping-design/` corpus is used (DEC-043); the methods
are textbook constrained-equilibrium and matrix structural analysis
(Przemieniecki, *Theory of Matrix Structural Analysis*; McGuire, Gallagher and
Ziemian, *Matrix Structural Analysis*). Standard claim fence applies (F-PIP-2;
claims taxonomy per DEC-081).

Run `python3 -I generators/skew_reference.py` in this directory to rebuild

`--write` rewrites them.

## Method

Every value is an exact rational (`fractions.Fraction`). A published value is
written as `{"exact": "n/d", "binary64": <float.hex of the nearest binary64>}`.
An irrational along-direction scalar is written as its exact square, its sign
and its correctly rounded binary64 value (decided by exact comparison with the
neighbouring midpoints).

Each admitted case is solved by two independent routes that must agree exactly:

- **Route K**, the constrained equilibrium (KKT) system
  `[K, −Cᵀ; C, 0][u; λ] = [f; g]`. The support-on-pipe reaction of constraint row
  c is λc, so `K u = f + Cᵀλ`.
- **Route N**, an exact nullspace basis of C from reduced row echelon form (not
  the product's canonical basis): `u = u₀ + N y` with `Nᵀ K N y = Nᵀ(f − K u₀)`,
  then λ from `Cᵀλ = K u − f`. That system must be consistent and λ unique.

A constraint set whose exact rank is below its row count is reported as
`SUPPORT_CONSTRAINT_REDUNDANT`. No tolerance is used anywhere.

The generator also asserts the adopted design's stated values (§2.6: S-1, R-1
to R-4), the spring-pair equivalence and the invariance groups.

## Sections of `references.json`

- **`direction_policy`.** Authored vectors with their expected class: `axis`
  (one nonzero component: today's path with the token for that axis), `skew` (the
  scale exponent s, the canonical scaled vector `2^s·d` with max|·| in [1, 2), the
  pivot, the basis columns `d_m e_j − d_j e_m` and the node matrix Q, all exact
  binary64), or a refusal code (`SUPPORT_DIRECTION_INVALID`, `…_ZERO`,
  `…_RANGE_UNSUPPORTED`). It includes 2^±600, 2^−1020 and subnormal-pair
  scalings, non-power-of-two factors (3, 0.75, and the binary64 0.1 whose double
  is exactly 0.2), negation and each range boundary.
- **`invariance`.** The groups whose outputs must be bit for bit identical
  (power-of-two factors), whose exact system must be identical (positive
  factors), and the negation pair.
- **`kernel`.** Single-node algebra on a tip with translational stiffness
  diag(k_a, k_b, k_c), in units of P and P/k: §2.6's S-1, S-2, R-1 to R-4, the
  axis-plus-stop reductions (|F| = 2 and |F| = 1), a redundant set, a
  near-dependent axis case (2^−500), a stop with a spring, and the S-K2 joint
  cases (two orthogonal stops, an oblique pair, a near-parallel pair at 2^−48, the
  parallel and antiparallel redundant pairs, three stops, an axis-restricted
  parallel pair). It includes the range regression `R4_tiny_restricted_direction`
  (d = (1, 2^−600, 0) with UX and UZ held: n_F = 2^−1200 rounds to 0, while the
  rescaled n_w is 1). Each single-stop case has an `attribution` block: F, the
  pivot on F, ŝ, w = 2^ŝ·d̃, n_w, the multiplier μ per unit w, each physical
  translation's free coordinates or `i32::MIN`, and the particular solution
  u₀. It also holds the S-K3 imposed-motion cases:
  - the moving guide at a stop's node;
  - meaning A alone and with axis rows, where the ground displacement is not
    a particular solution;
  - meaning B as a rational control and with irrational norms (d = (1,3,0) and
    (3,4,5)), written exactly as a + b√q with correctly rounded binary64 values.

  Each case names the slice that admits it and, if later than S-K1, the S-K1
  refusal code.
- **`mutant`.** The rounded-division basis for d = (1, 3, 0): its exact
  constraint residual per unit coordinate is 2^−54, so an exact check of the
  unrounded lift kills it.
- **`product`.** A guided cantilever (4 m member A–B along +X, anchor at A,
  rotations held at B), so B's translational stiffness is
  diag(EA/L, 12EI/L³, 12EI/L³). It uses w16's invented section leaves and
  material. Each case gives B's exact translations and every record's exact
  reaction: the anchor's six components, the rotation record's three moments,
  each axis record's component, and each skewed record's global force and
  along-direction scalar. It includes the byte-identity twins for an
  axis-aligned direction.
- **`modal_kernel`.** A point mass with a stop or a spring: the exact ω² (units
  k/m) of the restrained subspace, for the dynamics lane's consumers.
- **`regressions`.** The independent review's findings on revision 1, each
  asserted exactly by the generator:
  - the spring's along-direction value −k t/|d̃|, against the rejected chain
    (2/5 against 32/125 P);
  - reaction rows with and without a skewed spring block (r_z = 54/553 P
    without it);
  - the attribution range case;
  - the `i32::MIN` exponents of a stop-fixed node;
  - a ground displacement that violates an axis row, with the correct
    particular solution.
- **`attribution_range`.** Inputs r given directly to `attribute`. Each case
  gives exact μ, components, axis values and s², and design §7.2's binary64
  values (k, N′, μ′, μ, components, s). An overflowing N_w with finite published
  values is not refused; only a published value outside binary64 is.
- **`negatives`.** Every named refusal of the first slice, with its stage and
  inputs.

## Units

Kernel: forces in P, displacements in P/k. Product: N, m, rad. Published
reaction rows are support-on-pipe; the along-direction scalar is positive along
the authored +d.
