# T4-U2 bend references (T4-I7, repair round 01)

realized bends under `3.0.0/exact_pressure_v3` (H-2). Derived by the direct
unit-load (flexibility) method over the whole line, with no curved-element
stiffness, no K·u_free and no thermal analogy; nothing here is generated by
the product. Consumed by
`core/product_physics/tests/t4_u2_pressure_references.rs`.

## How the tests compare

|observed − expected| ≤ 1e-9·max(|expected|, zero_scale(group)) in both
solver modes, with each case's `zero_scale` block (translations converted to
the product's mm). Arc end rows are compared in the chord frame
(`chord_frame_elastic`) for the elastic `element_local_*` rows and along the
end tangent for `pipe_wall_endpoint_action_v2`; Lamé rows and the
straight-statics maximum must be absent on arcs.
