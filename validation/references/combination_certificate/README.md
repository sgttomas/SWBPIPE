# RT-A3 §4 combination-certificate references

These are frozen, independently derived expectations for the §4 combination
certificate. The governing text is DEL-05-02 Work
[`combination-certificate.md`](../../../execution/PKG-05/DEL-05-02/Work/combination-certificate.md)
§3 and `operating-case.md` §4.

Nothing here is generated by the product. The generator imports, reads and runs
no product code. All model data are invented, and no corpus equation or value is
used (DEC-043). Standard claim fence applies (F-PIP-2).

Status: candidate references, derived by their author TASK and not yet
independently refuted.

| File | Role |
|---|---|
| `generators/certificate_reference.py` | the generator: exact rationals, π by Machin's formula enclosed to 10^-120, the closed forms and the verdict classes the hand analysis decides |
| `references.json` | the inputs, P = p·A_i, the cantilever's subtractions and mechanics sum on EX and PF, and op1a V-2 and V-1 |
| `SHA256SUMS` | hashes of every file above |

`python3 -I generators/certificate_reference.py` rebuilds everything in memory
and compares it byte for byte; `--write` rewrites the outputs.

## What the references decide

- **Intended differences**: each derived group's component magnitudes |D_c|.
  The consumers check | |v_D,c| − |D_c| | ≤ B_D for every component, exactly.
  For a magnitude row they check (v_M − B_D)² ≤ ΣD_c² ≤ (v_M + B_D)².
- **Cancellation**: a group is `not_established` where the operands'
  publication gaps alone exceed the criterion. The rule is
  B_D ≥ B_O + B_S ≥ |fl(m_O) − m_O| + |fl(m_S) − m_S| − 2^-100(|m_O| + |m_S|)
  > RD(1e-9)·q_D, and it applies when the group is assessed
  (q_D ≥ 2^-34·S*_upper).
- **Floor**: every intended difference is exactly zero, so the group is below
  the floor whenever B_D < 2^-34·S*. The consumer checks that condition.
- **D-6**: on the EX cantilever's `comb:axial` (bit-identical pressure), each
  wall group names the elastic axial group at its location (none at the ends),
  and the wall groups' own verdict follows from the cancellation rule.
- **Gap operand**: op1a V-1's subtraction is not assessed, because both operands
  are gap-bearing (R1).
- **PF confirmed nonlinear**: op1a V-2's `comb:lift` gives dR = 5P/16,
  dM_A = 5PL/16 and the anchor dFz = 5P/16.

The W-16b line's `comb:S1` (linear EX subtraction) and `comb:K1` (mechanics) are
checked against the frozen exact rows of
[`../w16_exact_combinations/references.json`](../w16_exact_combinations/references.json).
