# First-static synthetic test fixtures

These twelve JSON files are byte-identical copies of the selected original case
inputs, reference values, selectors, criteria and section bindings. PROVENANCE.json
records each original Git/path/hash identity. Historical run evidence remains in
place; tests never need to read that dated directory.

The values support synthetic adapter/structure tests. They are not observed solver
outputs, a material/component library, engineering acceptance or a new admission.
The preserved JSON may cite historical preparation records as provenance; those
citations are inert metadata rather than executable test dependencies.

Derivation/integration tests create a minimal temporary package from these files.
They explicitly substitute test-only package/review metadata hashes and synthetic
review-record text, while retaining every original input, reference, selector,
criterion and section-binding byte. Runtime admission and production reference
bindings are unchanged. The full historical packet/review archive is not copied
here. Actual solver comparisons stay in their separate immutable run evidence.
