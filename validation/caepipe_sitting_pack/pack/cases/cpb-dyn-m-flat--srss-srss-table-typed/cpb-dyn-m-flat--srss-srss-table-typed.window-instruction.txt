1. Use this run if the dry run's check of the dry-run sample that carries the same spectrum table did not agree or was not made, or if its counterpart cpb-dyn-m-flat--srss-srss was switched to this run at its step 4 or 5; otherwise run its counterpart cpb-dyn-m-flat--srss-srss instead. Once switched to this run, do not return to cpb-dyn-m-flat--srss-srss.
2. Import cpb-dyn-m-flat--srss-srss-table-typed.mbf: File > Import from the Main window, select the file and click Import; it is the model file with the OPMISC record added and no spectrum table. [https://docs.sstcae.com/users_manual/import_mbf.htm, section "Format of .MBF" (CAEPIPE-IMPORT-MBF, execution/PKG-17/DEL-17-01/Source_Basis_Register.md), read 2026-11-12]
3. Options > Spectrum sets the units of the X- and Y-axes and the interpolation method: if it offers Frequency (Hz) for the X-axis and Acceleration (mm/sec2) for the Y-axis (the units the same page names for a spectrum) and a linear interpolation method (spectra are interpolated linearly or logarithmically), set them; otherwise skip this run, run nothing in its place and not its counterpart either, note it on the run line and go on to the next strike number. [https://docs.sstcae.com/users_manual/spectrums.htm (user's manual, "Spectrums"), read 2026-11-12; https://docs.sstcae.com/tech_manual/dynamic_analysis.htm (technical reference, "Dynamic analysis", section "Response Spectrum"), read 2026-11-12]
4. Select Spectrums from the Misc menu. [https://docs.sstcae.com/users_manual/spectrums.htm (user's manual, "Spectrums"), read 2026-11-12]
5. In the List window for spectrums, type a spectrum named DYNFLAT in the Name column with 2 pairs of values, each a frequency in Hz then an acceleration in mm/sec2: 0.125, 2500; 1000, 2500. [https://docs.sstcae.com/users_manual/spectrums.htm (user's manual, "Spectrums"), read 2026-11-12]
6. Under the menu Loads > Spectrum, type a Level Tag L1 ("Type an alpha-numeric name (up to 8 characters long) in this field."). The MBF has no documented record for the spectrum assignment, so it is entered here; the file's OPMISC record also states the two sums. [https://docs.sstcae.com/users_manual/load_cases.htm (user's manual, "Load cases"), read 2026-11-12; https://docs.sstcae.com/users_manual/spectrum_load.htm (user's manual, "Spectrum Load"), read 2026-11-13]
7. Double-click the row ("Double click on the row to assign the spectrum load."). [https://docs.sstcae.com/users_manual/spectrum_load.htm (user's manual, "Spectrum Load"), read 2026-11-13]
8. X, Y and Z spectrums ("Select a spectrum from the drop-down combo box, which should have been input in the spectrum table for each global direction."): X: DYNFLAT, Factor 1; Y: DYNFLAT, Factor 0.8; Z: DYNFLAT, Factor 0.6. [https://docs.sstcae.com/users_manual/spectrum_load.htm (user's manual, "Spectrum Load"), read 2026-11-13]
9. Factor ("The multiplying (scale) factor for the spectrum is input here.") is a pure multiplier of the spectrum's ordinates, with no unit. If the window offers one Factor per direction, enter each as the previous step states it. If the window offers a single Factor and this run states the same factor for every direction it loads, enter that value; if it states different factors for different directions, skip this run, run nothing in its place and not its counterpart either, note it on the run line and go on to the next strike number. [https://docs.sstcae.com/users_manual/spectrum_load.htm (user's manual, "Spectrum Load"), read 2026-11-13]
10. Mode Sum ("Pick one of three choices, SRSS (square root of sum of squares), Closely spaced or Absolute."): SRSS. [https://docs.sstcae.com/users_manual/spectrum_load.htm (user's manual, "Spectrum Load"), read 2026-11-13]
11. Direction Sum ("Pick one of two choices, SRSS (square root of the sum of squares) or Absolute."): SRSS. [https://docs.sstcae.com/users_manual/spectrum_load.htm (user's manual, "Spectrum Load"), read 2026-11-13]
12. Before the analysis, open Options > Analysis, tab Dynamics. [https://docs.sstcae.com/users_manual/analysis.htm (user's manual, "Analysis"), read 2026-11-12]
13. Check that Cutoff Frequency reads 900 Hz; a value that differs is set to the stated value by hand and noted on the run line. The vendor's public import page states the file's cutoff frequency value with no unit; Hertz is taken from the analysis page's description of the window's Cutoff Frequency field. If the tab does not show it, skip this run, run nothing in its place and not its counterpart either, note it on the run line and go on to the next strike number. [https://docs.sstcae.com/users_manual/import_mbf.htm, section "Format of .MBF" (CAEPIPE-IMPORT-MBF, execution/PKG-17/DEL-17-01/Source_Basis_Register.md), read 2026-11-12; https://docs.sstcae.com/users_manual/analysis.htm (user's manual, "Analysis"), read 2026-11-12]
14. Check that Number of Modes reads 7; a value that differs is set to the stated value by hand and noted on the run line. If the tab does not show it, skip this run, run nothing in its place and not its counterpart either, note it on the run line and go on to the next strike number. [https://docs.sstcae.com/users_manual/analysis.htm (user's manual, "Analysis"), read 2026-11-12]
15. Check that Include Missing Mass Correction is unchecked. If it is checked, uncheck it and note that on the run line. If the tab does not show it, skip this run, run nothing in its place and not its counterpart either, note it on the run line and go on to the next strike number. [https://docs.sstcae.com/users_manual/analysis.htm (user's manual, "Analysis"), read 2026-11-12]
16. Select the Misc tab ("On this tab you can set miscellaneous options."; the page gives Vertical Direction and Gravitational Acceleration and Direction under it). [https://docs.sstcae.com/users_manual/analysis.htm (user's manual, "Analysis"), read 2026-11-12]
17. Before the analysis, check the gravity the window shows against this run's request ("Gravitational Acceleration and Direction"): Vertical Direction Y; Gravitational Acceleration 9.80665 m/sec2; Direction of Gravity downward along Y (-Y). The page says to "click the “Change” button to modify the Gravitational Acceleration and the corresponding Direction of Gravity"; change nothing. If the window shows another value or direction, or does not show them, skip this run, run nothing in its place and not its counterpart either, note it on the run line and go on to the next strike number. [https://docs.sstcae.com/users_manual/analysis.htm (user's manual, "Analysis"), read 2026-11-12]
18. Loads > Load Cases: check the box next to Response Spectrum for analysis. [https://docs.sstcae.com/users_manual/load_cases.htm (user's manual, "Load cases"), read 2026-11-12]
19. Save the model as cpb-dyn-m-flat--srss-srss-table-typed.mod in this folder by the command you noted at the dry run. Do not save over the imported file. If the program will not save under that name, skip this run and note it. Run nothing in its place and not its counterpart either; go on to the next strike number.
20. Then analyze the model by File > Analyze (F12); the page says: "At the end of analysis, you are asked whether you want to “View results?” Click on OK to see results or Cancel to return to the main window." If the command is inactive ("Command “Analyze” in the “File” menu will become inactive when the model is not edited and “.res” file is available in the directory where the stress model “.mod” is stored."), skip this run, run nothing in its place and not its counterpart either, note it on the run line and go on to the next strike number. [https://docs.sstcae.com/users_manual/analyze__f12_.htm (user's manual, "Analyze (F12)"), read 2026-11-13]
21. In the Results window, open Print: File > Print (Ctrl+P). [https://docs.sstcae.com/users_manual/print__ctrl_p__2.htm (user's manual, "Print (Ctrl+P)"), read 2026-11-12]
22. Click All. [https://docs.sstcae.com/users_manual/print__ctrl_p__2.htm (user's manual, "Print (Ctrl+P)"), read 2026-11-12]
23. Click To File. [https://docs.sstcae.com/users_manual/print__ctrl_p__2.htm (user's manual, "Print (Ctrl+P)"), read 2026-11-12]
24. Save the .csv file as cpb-dyn-m-flat--srss-srss-table-typed.print.csv. [https://docs.sstcae.com/users_manual/print__ctrl_p__2.htm (user's manual, "Print (Ctrl+P)"), read 2026-11-12]
25. If the window does not offer a field as the page describes it, do not enter an equivalent; skip this run, run nothing in its place and not its counterpart either, note it on the run line and go on to the next strike number.
26. Optional: the next four steps export this run's saved model, and you may drop them; if you do, write "export not made" on the run line. If you drop it, what is lost is the program's own writing of the spectrum assignment and the analyses chosen, for which the vendor's public format page documents no record, and of the options it carries. Take them only if the dry run's check (v) found that the export dialog lets you set the file's name and folder. The file it writes records this run's saved model, cpb-dyn-m-flat--srss-srss-table-typed.mod, as the program holds it after this instruction's steps, including what was entered or set by hand; it is not the pack's model file. If any control in these steps is not offered as described, click Cancel if a dialog is open, write "export not made" and why on the run line; the run is complete.

[https://docs.sstcae.com/users_manual/export_mbf.htm (user's manual, "EXPORT MBF"; CAEPIPE-EXPORT-MBF, execution/PKG-17/DEL-17-01/Source_Basis_Register.md), read 2026-11-12]

[https://docs.sstcae.com/users_manual/export_mbf.htm (user's manual, "EXPORT MBF"; CAEPIPE-EXPORT-MBF, execution/PKG-17/DEL-17-01/Source_Basis_Register.md), read 2026-11-12]
