1. Import cpb-n-04--stop-axial-open.mbf: File > Import from the Main window, select the file and click Import. [https://docs.sstcae.com/users_manual/import_mbf.htm ("IMPORT MBF"; CAEPIPE-IMPORT-MBF, execution/PKG-17/DEL-17-01/Source_Basis_Register.md), read 2026-11-12]
2. In the Layout window, at node 30, enter a Limit Stop (type L in the Data column, or Limit Stop in the Data Types dialog) with the fields of the next steps. [https://docs.sstcae.com/tech_manual/limit_stop.htm (technical reference, "Limit Stop"), read 2026-11-12]
3. Upper limit: blank (no limit in front of the node along the direction, the node moves freely on that side).
4. Lower limit: 0 (the gap behind the node; zero makes a one-way restraint, no unit needed).
5. X comp: 1 (global X component, no unit).
6. Y comp: 0 (global Y component, no unit).
7. Z comp: 0 (global Z component, no unit).
8. Friction coefficient: blank (no friction).
9. Stiffness: Rigid (the default) (the page's default).
10. Connected to Node: blank (connected to the ground).
11. Leave every other field and record as imported.
12. Save the model as cpb-n-04--stop-axial-open.mod in this folder by the command you noted at the dry run. Do not save over the imported file. If the program will not save under that name, skip this run and note it. If you skip this run, run nothing in its place; go on to the next case.
13. Then analyze the model by File > Analyze (F12); the page says: "At the end of analysis, you are asked whether you want to “View results?” Click on OK to see results or Cancel to return to the main window." If the command is inactive ("Command “Analyze” in the “File” menu will become inactive when the model is not edited and “.res” file is available in the directory where the stress model “.mod” is stored."), skip this run, run nothing in its place, note it on the run line and go on to the next case. [https://docs.sstcae.com/users_manual/analyze__f12_.htm (user's manual, "Analyze (F12)"), read 2026-11-13]
14. In the Results window, open Print: File > Print (Ctrl+P). [https://docs.sstcae.com/users_manual/print__ctrl_p__2.htm (user's manual, "Print (Ctrl+P)"), read 2026-11-12]
15. Click All. [https://docs.sstcae.com/users_manual/print__ctrl_p__2.htm (user's manual, "Print (Ctrl+P)"), read 2026-11-12]
16. Click To File. [https://docs.sstcae.com/users_manual/print__ctrl_p__2.htm (user's manual, "Print (Ctrl+P)"), read 2026-11-12]
17. Save the .csv file as cpb-n-04--stop-axial-open.print.csv. [https://docs.sstcae.com/users_manual/print__ctrl_p__2.htm (user's manual, "Print (Ctrl+P)"), read 2026-11-12]
18. If the window does not offer a field as the page describes it, do not enter an equivalent; skip this run, run nothing in its place, note it on the run line and go on to the next case.
19. Optional: the next four steps export this run's saved model, and you may drop them; if you do, write "export not made" on the run line. If you drop it, what is lost is the program's own writing of the support record entered by hand (a limit stop). Take them only if the dry run's check (v) found that the export dialog lets you set the file's name and folder. The file it writes records this run's saved model, cpb-n-04--stop-axial-open.mod, as the program holds it after this instruction's steps, including what was entered or set by hand; it is not the pack's model file. If any control in these steps is not offered as described, click Cancel if a dialog is open, write "export not made" and why on the run line; the run is complete.
20. From the Layout window, choose File > Export ("To export a model, select the menu command File > Export from the Layout window."). [https://docs.sstcae.com/users_manual/export_mbf.htm (user's manual, "EXPORT MBF"; CAEPIPE-EXPORT-MBF, execution/PKG-17/DEL-17-01/Source_Basis_Register.md), read 2026-11-12]
21. In the Export Model dialog, choose "Model batch file (*.mbf)" as the Save as type ("The Export Model dialog is shown. Selecting the “Save as type” option as “Model batch file (*.mbf)” will export the stress model in CAEPIPE latest version."). [https://docs.sstcae.com/users_manual/export_mbf.htm (user's manual, "EXPORT MBF"; CAEPIPE-EXPORT-MBF, execution/PKG-17/DEL-17-01/Source_Basis_Register.md), read 2026-11-12]
22. Set the name cpb-n-04--stop-axial-open.export.mbf in this run's folder.
23. Click Export ("Once done, click on Export button to write to an .mbf file.") only if the dialog displays exactly the name cpb-n-04--stop-axial-open.export.mbf in this run's folder and no file of that name is already there. If it does not, or if anything would be written over, click Cancel and write "export not made" and why on the run line; the run is complete. [https://docs.sstcae.com/users_manual/export_mbf.htm (user's manual, "EXPORT MBF"; CAEPIPE-EXPORT-MBF, execution/PKG-17/DEL-17-01/Source_Basis_Register.md), read 2026-11-12]
