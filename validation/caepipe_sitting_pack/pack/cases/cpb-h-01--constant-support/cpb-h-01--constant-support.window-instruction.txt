1. Import cpb-h-01--constant-support.mbf: File > Import from the Main window, select the file and click Import. [https://docs.sstcae.com/users_manual/import_mbf.htm ("IMPORT MBF"; CAEPIPE-IMPORT-MBF, execution/PKG-17/DEL-17-01/Source_Basis_Register.md), read 2026-11-12]
2. In the Layout window, at node 30, enter a Constant Support (type cons in the Data column, or Constant Support in the Data Types dialog) with the fields of the next steps. [https://docs.sstcae.com/tech_manual/constant_support.htm (technical reference, "Constant Support"), read 2026-11-12]
3. Number of Hangers: 1 (a count, no unit; the support pushes up with a constant force the program calculates).
4. Tag: blank (no tag).
5. Connected to Node: blank (connected to the ground).
6. Leave every other field and record as imported.
7. Save the model as cpb-h-01--constant-support.mod in this folder by the command you noted at the dry run. Do not save over the imported file. If the program will not save under that name, skip this run and note it.
8. Then analyze the model by File > Analyze (F12); the page says: "At the end of analysis, you are asked whether you want to “View results?” Click on OK to see results or Cancel to return to the main window." [https://docs.sstcae.com/users_manual/analyze__f12_.htm (user's manual, "Analyze (F12)"), read 2026-11-13]
9. Then print the results to file: in the Results window, File > Print (Ctrl+P), click All, then To File, and save the .csv file as cpb-h-01--constant-support.print.csv. [https://docs.sstcae.com/users_manual/print__ctrl_p__2.htm (user's manual, "Print (Ctrl+P)"), read 2026-11-12]
10. Optional: the next four steps export this run's saved model, and you may drop them; if you do, write "export not made" on the run line. Take them only if the dry run's check (v) found that the export dialog lets you set the file's name and folder. The file it writes records this run's saved model, cpb-h-01--constant-support.mod, as the program holds it after this instruction's steps, including what was entered or set by hand; it is not the pack's model file.
11. From the Layout window, choose File > Export ("To export a model, select the menu command File > Export from the Layout window."). [https://docs.sstcae.com/users_manual/export_mbf.htm (user's manual, "EXPORT MBF"; CAEPIPE-EXPORT-MBF, execution/PKG-17/DEL-17-01/Source_Basis_Register.md), read 2026-11-12]
12. In the Export Model dialog, choose "Model batch file (*.mbf)" as the Save as type ("The Export Model dialog is shown. Selecting the “Save as type” option as “Model batch file (*.mbf)” will export the stress model in CAEPIPE latest version."). [https://docs.sstcae.com/users_manual/export_mbf.htm (user's manual, "EXPORT MBF"; CAEPIPE-EXPORT-MBF, execution/PKG-17/DEL-17-01/Source_Basis_Register.md), read 2026-11-12]
13. Set the name cpb-h-01--constant-support.export.mbf in this run's folder.
14. Click Export ("Once done, click on Export button to write to an .mbf file.") only if the dialog displays exactly the name cpb-h-01--constant-support.export.mbf in this run's folder and no file of that name is already there. If it does not, or if anything would be written over, click Cancel and note it on the run line. [https://docs.sstcae.com/users_manual/export_mbf.htm (user's manual, "EXPORT MBF"; CAEPIPE-EXPORT-MBF, execution/PKG-17/DEL-17-01/Source_Basis_Register.md), read 2026-11-12]
15. If the window does not offer a field as the page describes it, skip this case and note it on the run line; do not enter an equivalent.
