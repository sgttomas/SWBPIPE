1. Use this run only if the dry run's check of the dry-run sample that carries the same spectrum table agreed (the owner compared the table the program showed with the stated values and noted agreement on that sample's run line); otherwise run its counterpart cpb-dyn-c-n02-flat--abs-abs-table-typed instead.
2. Import cpb-dyn-c-n02-flat--abs-abs.mbf: File > Import from the Main window, select the file and click Import; it is the model file with the OPMISC and SPCMS records added. [https://docs.sstcae.com/users_manual/import_mbf.htm, section "Format of .MBF" (CAEPIPE-IMPORT-MBF, execution/PKG-17/DEL-17-01/Source_Basis_Register.md), read 2026-11-12]
3. Select Spectrums from the Misc menu. [https://docs.sstcae.com/users_manual/spectrums.htm (user's manual, "Spectrums"), read 2026-11-12]
4. If the List window for spectrums shows a spectrum named DYNFLAT with these 2 pairs of values, 0.125 Hz, 2500 mm/sec2; 1000 Hz, 2500 mm/sec2, go on; otherwise skip this run and note it on the run line. [https://docs.sstcae.com/users_manual/spectrums.htm (user's manual, "Spectrums"), read 2026-11-12]
5. If Options > Spectrum, which sets the units of the X- and Y-axes and the interpolation method, shows the X-axis unit Frequency (Hz), the Y-axis unit Acceleration (mm/sec2) and a linear interpolation method, go on; otherwise skip this run and note it on the run line. [https://docs.sstcae.com/users_manual/spectrums.htm (user's manual, "Spectrums"), read 2026-11-12]
6. Under the menu Loads > Spectrum, type a Level Tag L1 ("Type an alpha-numeric name (up to 8 characters long) in this field."). The MBF has no documented record for the spectrum assignment, so it is entered here; the file's OPMISC record also states the two sums. [https://docs.sstcae.com/users_manual/load_cases.htm (user's manual, "Load cases"), read 2026-11-12; https://docs.sstcae.com/users_manual/spectrum_load.htm (user's manual, "Spectrum Load"), read 2026-11-13]
7. Double-click the row ("Double click on the row to assign the spectrum load."). [https://docs.sstcae.com/users_manual/spectrum_load.htm (user's manual, "Spectrum Load"), read 2026-11-13]
8. X, Y and Z spectrums ("Select a spectrum from the drop-down combo box, which should have been input in the spectrum table for each global direction."): Y: DYNFLAT, Factor 1; Z: DYNFLAT, Factor 1; and no spectrum for X (if the window requires a spectrum for every direction, skip this run and note it). [https://docs.sstcae.com/users_manual/spectrum_load.htm (user's manual, "Spectrum Load"), read 2026-11-13]
9. Factor ("The multiplying (scale) factor for the spectrum is input here.") is a pure multiplier of the spectrum's ordinates, with no unit. If the window offers one Factor per direction, enter each as the previous step states it. If the window offers a single Factor and this run states the same factor for every direction it loads, enter that value; if it states different factors for different directions, skip this run and note it. [https://docs.sstcae.com/users_manual/spectrum_load.htm (user's manual, "Spectrum Load"), read 2026-11-13]
10. Mode Sum ("Pick one of three choices, SRSS (square root of sum of squares), Closely spaced or Absolute."): Absolute. [https://docs.sstcae.com/users_manual/spectrum_load.htm (user's manual, "Spectrum Load"), read 2026-11-13]
11. Direction Sum ("Pick one of two choices, SRSS (square root of the sum of squares) or Absolute."): Absolute. [https://docs.sstcae.com/users_manual/spectrum_load.htm (user's manual, "Spectrum Load"), read 2026-11-13]
12. Before the analysis, open Options > Analysis, tab Dynamics. [https://docs.sstcae.com/users_manual/analysis.htm (user's manual, "Analysis"), read 2026-11-12]
13. Check that Cutoff Frequency reads 900 Hz and Number of Modes 5; a value that differs is set to the stated value by hand and noted on the run line. The vendor's public import page states the file's cutoff frequency value with no unit; Hertz is taken from the analysis page's description of the window's Cutoff Frequency field. [https://docs.sstcae.com/users_manual/import_mbf.htm, section "Format of .MBF" (CAEPIPE-IMPORT-MBF, execution/PKG-17/DEL-17-01/Source_Basis_Register.md), read 2026-11-12; https://docs.sstcae.com/users_manual/analysis.htm (user's manual, "Analysis"), read 2026-11-12]
14. Check that Include Missing Mass Correction is unchecked. If the tab does not show one of these fields, skip this run and note it on the run line. [https://docs.sstcae.com/users_manual/analysis.htm (user's manual, "Analysis"), read 2026-11-12]
15. Before the analysis, check the gravity the window shows against this run's request ("Gravitational Acceleration and Direction"): Vertical Direction Y; Gravitational Acceleration 9.80665 m/sec2; Direction of Gravity downward along Y (-Y). The page says to "click the “Change” button to modify the Gravitational Acceleration and the corresponding Direction of Gravity"; change nothing. If the window shows another value or direction, or does not show them, skip this run and note it on the run line. [https://docs.sstcae.com/users_manual/analysis.htm (user's manual, "Analysis"), read 2026-11-12]
16. Loads > Load Cases: check the box next to Response Spectrum for analysis. [https://docs.sstcae.com/users_manual/load_cases.htm (user's manual, "Load cases"), read 2026-11-12]
17. Save the model as cpb-dyn-c-n02-flat--abs-abs.mod in this folder by the command you noted at the dry run. Do not save over the imported file. If the program will not save under that name, skip this run and note it.
18. Then analyze the model by File > Analyze (F12); the page says: "At the end of analysis, you are asked whether you want to “View results?” Click on OK to see results or Cancel to return to the main window." [https://docs.sstcae.com/users_manual/analyze__f12_.htm (user's manual, "Analyze (F12)"), read 2026-11-13]
19. Then print the results to file: in the Results window, File > Print (Ctrl+P), click All, then To File, and save the .csv file as cpb-dyn-c-n02-flat--abs-abs.print.csv. [https://docs.sstcae.com/users_manual/print__ctrl_p__2.htm (user's manual, "Print (Ctrl+P)"), read 2026-11-12]
20. If the window does not offer a field as the page describes it, skip this case and note it on the run line; do not enter an equivalent.
Only if the command you noted at the dry run lets you choose the saved file's name and folder: instead of importing this run's file, you MAY, with the model of this case's comparable run (cpb-dyn-c-n02-flat--srss-srss) still open, change Mode Sum to Absolute and Direction Sum to Absolute in Loads > Spectrum, save the model as cpb-dyn-c-n02-flat--abs-abs.mod in this run's folder by the command you noted at the dry run, analyze it by File > Analyze (F12), print the results to file as cpb-dyn-c-n02-flat--abs-abs.print.csv, and write on this run's run line that the setting was made by hand. Importing this run's file remains the default. [https://docs.sstcae.com/users_manual/spectrum_load.htm (user's manual, "Spectrum Load"), read 2026-11-13]
