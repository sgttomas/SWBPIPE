## Current model format

**Choice.** B7 defined model document 0.5.0 (HELP_HUMAN accepted this design on 2026-10-10; DEL-02-05 CLM-003 and DEL-04-07 Design point to it). Neither former exact version expressed models with and without pressure as one format: 0.3.0 and 0.4.0 both required the exact contract (`PRESSURE_CONTRACT_REQUIRED`), so a pressure-free model that needs the preview route, such as the G10 milestone model (W1 route L), could not be written in either, and writing it as 0.3.0 would move it onto route E. Widening either in place was ruled out: it would change what an existing version can contain, against DEC-033's rule that such a change bumps the minor version, and behaviour would stay keyed on a version that means two things.

**Since the T4-U4b/U5b epoch, model document 0.6.0 was current.** Under HELP_HUMAN's 2026-10-13 ruling, that epoch made 0.6.0 the one current version and retired 0.5.0 by name, with no migration (DEL-04-07 Design `u4b-u5b-implementation.md` §1.1, "Model document 0.6.0"). 0.6.0 keeps every 0.5.0 rule below and adds the U4b/U5b input fields that section lists.

**At W-13 S1b, model document 0.7.0 became current** (owner OD-4, 2026-10-23; DEL-02-01 Design `model-document-0.7.0.md` §2). 0.7.0 is 0.6.0 plus optional annotation and record slots that no solve reads (tags, notes, lines, unresolved assumptions, rule-pack references, structured provenance, constraints and equipment interfaces); 0.6.0 is retired by name with the re-author diagnostic, and nothing is migrated. Every rule below holds unchanged.

**Since W-15 slice c, model document 0.8.0 is current** (owner ruling, 2026-10-26: "R-c1 A, 0.8.0 a2"; DEL-02-01 Design `model-document-0.8.0.md`). It adds the reducer's optional `geometry.eccentric_offset` and the optional `model_settings.shear_model` (§1.1 of that design); 0.7.0 is retired by name, with no migration. The geometry, mechanics and stored-work rules are in that design and DEL-03-05 Design `eccentric-reducer-offset.md`.

**Model document 0.8.0** is the only current version:
- **`pressure_contract` is optional.**
  - Absent: the document is pressure-free and solves on the preview route. `pressure_regions` and every pressure primitive are refused by name.
  - Present: it names the current exact contract (v3), and every case carries `pressure_regions`, with `[]` when it is unpressurized.
  - On an exact-contract document, the corrosion-allowance field (zero allowed) and the shear-model field are required, and absence is refused by name (owner, 2026-10-12, O2/O3). T4-U6 and U8 admit a nonzero allowance and `shear_model = timoshenko_annulus_energy_v1` (DEL-05-03 Design `section-bases-and-timoshenko.md`). T4 supplies the field specification; the current schema carries both fields, and every B7b re-authored fixture states allowance 0 and `euler_bernoulli` unless it deliberately tests a refusal.
- **The load/reference-state group is optional as a whole.** When present (`reference_configurations`, material `expansion_laws`), it carries the former 0.4.0 rules (an explicit `analysis_state` on every case) and requires the exact contract.
- **Behaviour keys on presence.** It keys on whether the contract and the group are present, never on the version string.
- **Every other version is refused by name**. Older parsed versions receive the re-author refusal; newer versions and missing, non-string or unparseable versions are refused without coercion or down-migration. Nothing is migrated. The desktop, the applier and Python persistence use the four states in DEL-02-01 Design `model-document-0.8.0.md` §3.1.

**Exact-contract fields (owner, 2026-10-12, O2/O3; T4's field specification).** An exact-contract document is a current-version document with `pressure_contract` present.
- `section.corrosion_allowance` (a local sibling of `mill_tolerance` in `PipeSectionInput`): a length Quantity, finite and ≥ 0; zero is an explicit value, not a default. Meaning (D-5): reduced wall = wall − mill_tolerance − corrosion_allowance; reduced bore r_i = OD/2 − wall + mill_tolerance + corrosion_allowance; mill_tolerance + corrosion_allowance < wall_thickness. Required on every pipe section used by a member whenever `pressure_contract` is present. Refusals by name: absent on an exact-contract document, `EXACT_PRESSURE_CORROSION_ALLOWANCE_REQUIRED` (model-incomplete; names the pipe and the field); present on a pressure-free document, `CORROSION_ALLOWANCE_WITHOUT_PRESSURE_CONTRACT`; non-finite, negative, wrong dimension or a sum ≥ wall, the existing quantity/section codes; nonzero, refused before T4-U6 as `EXACT_PRESSURE_CORROSION_ALLOWANCE_UNSUPPORTED` and admitted since T4-U6 under the D-5 bases. Zero is admitted and changes nothing. Authored null and malformed quantities fail typed decoding; neither becomes missing or zero. Shared preview section binding remains OD/wall-only and preserves this local supplement through assign, rematerialize, detach and split. Canonical `Section.properties.corrosion_allowance` is a separate code-neutral Quantity representation, with no flattening adapter, top-level Section alias or shared propagation.
- `pressure_contract.shear_model`, per document (the canonical member of the `PressureContract` object; no top-level compatibility alias): `euler_bernoulli` | `timoshenko_annulus_energy_v1`, applying to straight members only (arcs stay Euler–Bernoulli, disclosed). Required when `pressure_contract` is present. Refusals by name: absent, `EXACT_PRESSURE_SHEAR_MODEL_REQUIRED`; present on a pressure-free document, `SHEAR_MODEL_WITHOUT_PRESSURE_CONTRACT`; unknown, the existing enum/shape refusal; `timoshenko_annulus_energy_v1`, refused before T4-U8 as `EXACT_PRESSURE_SHEAR_MODEL_UNSUPPORTED` and admitted since T4-U8.
