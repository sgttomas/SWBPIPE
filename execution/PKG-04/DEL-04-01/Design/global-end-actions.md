# Member end actions in global coordinates (W-7)

Standard claim fence applies (F-PIP-2; claims taxonomy per DEC-081).

## Purpose

PRD FR-SOL-007 (Must): "Element-end forces/moments are available in local and
global coordinates." Straight pipes and curved bends publish their twelve end
rows in `element_local` (`append_element_force_results`; bends in their
end-tangent frames) and, beside them, twelve global end rows
(`append_element_global_end_results`), on both routes. Connectors publish their
own global end actions (`joint::connector_rows`). This deliverable owns the
local-to-global transform (REQ-004).

## Ruling

**The global rows are exactly the rotation of the published local end rows.**
For each straight member and each realized curved bend, at each end
e ∈ {end_i, end_j}, with f_e the published local force (axial, shear y, shear
z) and m_e the published local moment (torsion, bending y, bending z) at that
end, and R_e the 3×3 matrix whose rows are that end's local axes expressed in
global coordinates:

    F_e = R_eᵀ f_e,   M_e = R_eᵀ m_e

computed in binary64 from the published values. Consequences:
- **Straight members:** R_i = R_j = the element's `local_axes` (from its
  `y_reference`).
- **Curved bends:** R_e is the end-tangent frame the local rows use at that end
  (`curved_bend_end_axes`): tangent, inward normal, plane normal.
- **Sign convention:** the local rows are node-on-element end actions, so the
  global rows are the global action **on the element at its node**; the
  element acts on its node with −F, −M. This is the connector rows' convention
  ("global end action on the connector at its node (node on element)").
- **EX pressure members** (Agent 0, 2026-10-23): EX removes the local axial
  rows on pressure members and keeps the shear and moment rows. The rotated
  axial component is the published wall force (`pipe_wall_endpoint_action_v2`),
  and the shear and moment components are the published local rows. The
  internal `corrected_local_forces` vector is never rotated wholesale: on
  certified bends it holds the elastic force, not the wall force. A pressure
  member's global force is therefore the wall's end action, not the effective
  force S = N_w − p·A_i; the basis string says so.
- **Certified cases:** the local rows may be certified (bend axes formed at
  128 bits); the rotated rows are binary64 values computed from the published
  local rows and receive no certificate of their own. The basis string says
  so, and the recovery guard does not judge them.
- **No extra sign flip:** the bend end fix-up changes metadata only; the
  published values are rotated as they are.

## Rows

Twelve rows per member per case, after the member's local end rows:

| Field | Value |
|---|---|
| `id` | `result:element-global-end:{stable_suffix(member)}:{end_i\|end_j}:{fx\|fy\|fz\|mx\|my\|mz}` (load-case prefixed as other rows are) |
| `kind` | `element_global_end_force_v1` (components `Fx`, `Fy`, `Fz`, unit `N`) and `element_global_end_moment_v1` (`Mx`, `My`, `Mz`, unit `N*m`) |
| `entity_ref` | the member (pipe) id |
| `metadata.coordinate_system` | `global` |
| `metadata.location` | `end_i` or `end_j` |
| `metadata.basis` | `rotated_from_published_element_local_end_actions_v1` (on EX pressure members, `rotated_from_published_element_local_end_actions_v1;axial_is_pipe_wall_action`) |
| `metadata.sign_convention` | "global end action on the element at its node (node on element), F = Rᵀ f; the element acts on its node with −F" |

## Consumers

- **Semantic contract tables** (`fixtures/results/semantic_contract_v0_3_*`,
  generated by `tools/serialization/semantic_contract_tables.py`): the two
  kinds are added as signed, linear (`combination_algebra: signed_linear`),
  force and moment dimensions, to every table whose producer publishes member
  rows. The contract ids are not bumped: the change adds kinds and removes or
  redefines none. The tables are `REVIEWED_INPUTS`, so the build identity
  changes.
- **Combinations (PF):** the kinds join the signed linear state kinds, so a
  mechanics combination of global end rows is the factored sum of each case's
  global rows (rotation is linear, so this equals the rotation of the combined
  local rows to rounding).
- **Formation guard:** the kinds are not added to its action classes. Its
  stress-free notice bounds the guarded groups (|N|, hypot(V_y, V_z), |T|,
  hypot(M_y, M_z)), which do not bound a rotated component by themselves, so
  the notice's sentence is scoped to the element-local member rows and the
  support rows it actually bounds.
- **Retained precision** (dormant in v0.1, DEL-04-08 B8): the retained route's
  admission gate counts every row of the ordinary envelope. The ordinary
  envelope carries the global end rows on every run, watched or not ("the
  observed run is the plain run"), so the priced bound is **78 rows per
  member**: P_FINAL = 7n + 78m + 8g + 3 and, on the exact route,
  P_FINAL_EXACT = 7n + 114m + 8g + 3 (`retained_memory.rs`; Agent 0,
  2026-10-23, option A). DEL-04-08 `retained-pricing-rules.md` §8.20 records
  the re-registration, the bounds that lean on the row counts and the fit of
  every priced phase against M = 12 GiB; a phase that no longer fits would
  stop the work for the owner (decision 22). A W1 successor carries the rows
  as named not-covered rows (`GLOBAL_END_ROWS_NOT_COVERED`), completed from
  its projected end actions. The retained method is dormant in v0.1, so this
  changes nothing a user sees.
- **Source-recovery publications** (source-selected cases): the composite
  receipt admits only qualified physical rows, so these publications omit the
  new rows by a named rule (`global_end_rows_published`).
- **Readers:** the EX evidence validator checks the new rows explicitly
  (kind, unit, location, coordinate system, basis, one row per member, end and
  component); malformed rows are refused by name.
  The readers also check that each end's global vector has the norm of the
  local vector it rotates, an internal-consistency check that does not
  establish direction. Its bound is the frame error the kernel admits
  (`AXIS_TOLERANCE` = t = 1e-12 per axis length and per pair) plus 64 epsilon
  of rounding: R Rᵀ = I + E with |E_ii| ≤ 2t + t² and |E_ij| ≤ t, so
  ‖E‖₂ ≤ ‖E‖_F ≤ √(3(2t + t²)² + 6t²) < 5t, and the bound is 5t relative.
  A near-parallel `y_reference` the kernel admits gives axes 2.46e-13 from
  orthogonal, which a bound of rounding alone refused. The derived bend end
  frames (`curved_bend_end_axes`) pass no separate admission check; their
  worst error is about 2.5t (independent review), which the bound covers.
- **Desktop, exports, verifiers:** the desktop's declared result dimensions,
  the stress-neutral export's family mapping and the Python verifiers read the
  new kinds from the tables or list them explicitly.
- **Desktop element axes and frame filter (A7, DEL-07-05):** the viewport's
  local-axis triads form the straight-member frame above from the node
  coordinates and `y_reference` in TypeScript (`elementAxes.ts`); realized
  curved bends get none. `elementAxes.test.ts` rotates the bundled
  reference's published local end rows with those axes and recovers its
  global end rows. The results table states each row's
  `metadata.coordinate_system` and filters by it; it never re-projects a
  value.

## Evidence

- A frame whose members point along every axis and an inclined member, on
  PF: global rows equal Rᵀ times the published local rows, with R computed
  independently from the node coordinates and `y_reference`. At every node,
  −Σ_incident F + P_external + R_support = 0 (R_support the support's action
  on the pipe), and the analogous moment balance, to the 1e-9 criterion.
- A frame with a realized curved bend: the same nodal balance holds at both
  bend ends with the neighbouring straight members, which checks the end-tangent
  rotation independently of the local rows' frame.
- EX pressure models: the rotated axial projection equals the published wall
  action. Nodal balance holds only when the physical pressure loads at the
  node are included (transferred end caps, bend-junction remainders, joint
  attachment loads; not the recovered eigenloads). A capped, freely extending
  pressure pipe has wall force p·A_i and zero reaction, so a balance against
  user loads alone fails by p·A_i. The evidence states which balance it
  checks.
- Combinations: the combined global row equals the factored sum.
- Readers and exports round-trip the rows; malformed rows are refused.
- The W-9 L-frame (PR #1548) on PF: global end rows at the corner C balance to
  zero, and at A and D equal the frozen reactions (independent reference).
