# Remaining physics evaluation protocol — Owner steering amendment V2

## Authority update

After protocol V1 was written and before any child was dispatched, HELP_HUMAN relayed the Owner's new direction: P0 may exercise engineering judgment, select defensible modelling approaches from necessary evidence, document assumptions, and recommend bounded implementation fences. Future comparison with industry-standard solvers is a planned validation phase and must not be represented as completed evidence.

This amendment supersedes V1 only where V1 routed every new engineering meaning back as an undecided Owner choice. P0 and its bounded children must instead resolve choices they can defend from vetted primary sources, mechanics consistency, current product scope, and falsifiable verification design. A choice remains preference/accountability limited only when evidence cannot resolve materially different valid product meanings.

## Updated decision criterion

For pressure, friction history/reference, contact initialization, connector interpretation, dimensional basis, solver diagnostics, and physical-to-analytical bridging:

1. identify any current reproducible correctness gap;
2. compare the smallest credible approaches;
3. select a recommended approach when engineering evidence supports one;
4. state assumptions, applicability limits, public-compatibility impact, and an independent refutation plan;
5. define a bounded source/test fence for WORKING_ITEMS where appropriate.

New source writes remain outside P0 authority. Formal decomposition, dependency, lifecycle, register, decision, receipt, public-contract adoption, and Git changes remain outside P0 authority. A compatibility design may be recommended without stopping the evaluation. The assessment must not expand into an unbounded physics program.
