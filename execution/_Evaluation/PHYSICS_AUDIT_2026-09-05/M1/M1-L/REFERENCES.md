# References, independence, and criteria

The frozen analytical basis is EXPECTED_V1.md and EXPECTED_V2.md, written before their comparisons. These are original elementary numerical derivations, not extracted piping-design equations. All quantities are invented numerical inputs. No engineering suitability threshold was inferred from results.

1. **Scalar and 2x2 equations:** Direct multiplication verifies the expected solutions. The finite extreme 2x2 example has an exactly representable solution [0,1]; rejection of an intermediate nonfinite computation is acceptable software behavior, but successful NaNs are not. The scalar overflow case has an unrepresentable exact solution and is solely an error-handling check.
2. **SPD constructed matrices:** The harness freezes a deterministic integer generator B and x, forms A=B^T B+I and f=A*x before calling any solver. SPD follows algebraically. This avoids using dense results as the expected sparse answer. Sizes1,2,3,6,12,24, three public solve paths. Fixed integer formula, no random seed. Forward errors and high-precision Decimal residual/backward errors are observations; no universal acceptance bar is asserted.
3. **Boundary elimination:** Partitioning K*u=f yields K_ff*u_f=f_f-K_fc*u_c. The exact 2x2 fixture produces reduced stiffness3, load6, and u_f2. Full prescription produces the valid zero-dimensional solve. Duplicate/range/vector errors are interface checks.
4. **Tridiagonal spectrum:** Substitute v_i=sin(i*j*pi/(n+1)) into 2v_i-v_(i-1)-v_(i+1), with endpoints zero. The resulting eigenvalues are2-2cos(j*pi/(n+1)). The ratio of extreme eigenvalues gives440.6885603836566 for n32. This analytic reference is independent of the production Jacobi method. V1 subsequently corroborated the derivation after the initial report; that is review evidence, not retroactive pre-execution freezing.
5. **Diagonal spectrum:** diag(1e-10,1) has condition1e10; diag(0,1) is singular. These exact references test the private numerical helper, not product-supported unstable models.
6. **Existing chain8 spectrum:** Actual production assembly/reduction matrix is intentionally the subject. NumPy2.5.1 LAPACK eigh is an independent numerical implementation for that same matrix, not an independent mechanics formulation. Eigenpair residual2norm3.969e-6 against matrix norm7.730e9 and minimum eigenvalue3580.809, with orthogonality error3.130e-15, make the factor3.487 condition discrepancy substantially larger than reference numerical uncertainty. Full configuration is ENVIRONMENT.json. No independent physical benchmark is claimed by this comparison.
