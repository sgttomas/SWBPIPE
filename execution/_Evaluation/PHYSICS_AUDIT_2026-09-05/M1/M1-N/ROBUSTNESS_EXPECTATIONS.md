# Supplement expectations before execution
Public Rust fields permit constructor bypass. Invalid max_iterations=0 should return a typed invalid-input error rather than panic at a Result API; this is robustness, not ordinary serialized product reachability. Public NaN trial displacement/reaction should not classify a unilateral state as valid; trial constructors already reject such values. Duplicate support identities should not silently yield ambiguous duplicated final states; direct caller only until product reachability proven. Duplicate active boundary must produce error; missing seed must produce error. These observations introduce no physical assumptions or numerical thresholds. Production constructor paths are separately protected; audit does not claim a native GUI crash.
