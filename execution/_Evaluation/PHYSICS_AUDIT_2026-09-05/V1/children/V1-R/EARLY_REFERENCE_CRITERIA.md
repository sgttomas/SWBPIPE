# Frozen independent reference criteria — V1-R early packet

Basis: source 2be412ccea62bdc4bd96deb082c46d7a792076ea; approved audit plan; no production observations used to tune the expectations below. These are equation identities and applicability constraints, not newly approved engineering acceptance tolerances.

1. Unit representation: normalize all length dimensions before mechanics; equivalent m/mm/in models have the same SI stiffness/load problem. Rigid translation cannot change relative geometry or mechanical response. Rotation requires simultaneous transformation of loads, supports and vector/tensor outputs; partial rotation is not a valid test.
2. Selected nonlinear state: after convergence, the single selected displacement vector must drive nodal rows and element recovery. For a one-DOF linear elastic body k with an upper rigid stop g under positive force F: u=min(F/k,g); contact force magnitude=max(F-k*g,0). For an independent linear parallel spring ks, replace k with k+ks. This static contact oracle assumes no friction/history and a stable positive stiffness.
3. Reaction magnitude: force norm=sqrt(Fx²+Fy²+Fz²) [N], moment norm=sqrt(Mx²+My²+Mz²) [N m]. No physically meaningful norm combines all six without an explicit reference length and a different declared meaning. Pure applied moment gives zero net support force but a nonzero moment.
4. Linear spring preservation: positive elastic spring contributions add to the assembled stiffness whether or not an unrelated nonlinear support exists. Scalar supported translation gives u=F/(k+ks), not F/k.
5. Uniform-load cantilever, length L, transverse signed load q: section force magnitude |q|(L-x); bending magnitude |q|(L-x)²/2; tip magnitude |q|L⁴/(8EI). Fixed-fixed uniform-load member: clamped displacement DOFs zero while interior moments are nonzero; |end moment|=|q|L²/12 and opposite-sign midspan magnitude |q|L²/24. Endpoint interpolation alone misses the quadratic field. Distributed point jumps require explicit left/right convention.
6. Stability: a freely translating scalar body stabilized by k>0 has unique u=F/k. Constraint counts alone cannot establish rank; a nonlinear-restraint stabilized case additionally needs a feasible active state and a declared initialization/continuation contract. Failure to solve an unsupported initial state is not automatically an incorrect numerical answer.
7. Identity: same input+settings must be reproducible; changed mechanics input must have distinguishable model/settings provenance. A constant label alone is not a numerical defect if the surrounding model/state identity is complete. Inspect the whole contract.

Representative reference equations: axial u=FL/(EA); torsion theta=TL/(GJ); free thermal delta=alpha*DeltaT*L, full axial restraint N=-EA*alpha*DeltaT; circular section A=pi(Do²-Di²)/4, I=pi(Do⁴-Di⁴)/64, J=2I, Z=I/(Do/2); axial stress N/A, bending M/Z, circular torsional shear T*(Do/2)/J. Thin-wall pressure formulas require their declared radius/wall convention and physical approximation. Curved macro-elements require independent unit-load energy integrals with the same declared axial/bending/torsion assumptions; chord-beam agreement is not an oracle.

Linear residual evidence should include componentwise force/moment units, normwise backward error ||b-Ax||/(||A||||x||+||b||), scaling and conditioning. Small backward error does not establish small forward error for an ill-conditioned problem. No generic acceptance threshold is created here.

Nonlinear convergence_observations.md explicitly reports implementation-measured iteration/delta envelopes; these are regression observations, not independent physical oracles.
