# Wind contract calibration supplement

Manager requested proof that repeating a whole-span reference is invalid rather than intentional load multiplicity. The existing authoring validator establishes exactly that contract: `core/model_operations/operation_applier/src/rich_authoring.rs:658` parses the same exposed_pipe_refs/exposed_spans shape; lines667–674 insert whole references into a HashSet and return `Duplicate whole wind exposure` on repetition. The same validator rejects whole-plus-partial and overlapping partial records. Thus the native physics boundary currently accepts and numerically doubles an input the existing authoring boundary rejects. This is an actual validation-parity defect for loaded/direct model payloads, not an assumed unique-list design rule. Normal approved authoring operations already block it, limiting practical exposure.

Additionally the generator constructs both duplicate records with the same deterministic load identity, and prepare_loads iterates them without duplicate-ID checking. Doubling is therefore not represented as two separately identified intentional loads. C-05 remains reproduced; fix recommendation is to align native boundary validation with the existing authoring contract. This supplement supersedes the narrower unsupported uniqueness rationale, without changing original raw outputs or frozen oracles. No new public uniqueness policy is proposed.
