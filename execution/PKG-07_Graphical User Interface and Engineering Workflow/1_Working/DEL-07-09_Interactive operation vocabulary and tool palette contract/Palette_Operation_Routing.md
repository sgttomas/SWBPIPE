## Common executable route

`apps/desktop/src/features/toolkit/capabilityCatalog.ts::toolkitCapabilities` is the executable command catalog. `App.tsx::handleToolkitCommand` changes focus/tool selection only. Forms build explicit intents; model edits pass through `apps/desktop/src/services/operationService.ts::validateModelOperation,applyModelOperation` or `apps/desktop/src/services/operationBatchService.ts::validateOperationBatch,applyOperationBatch`. Both native Tauri and browser Wasm call the same Rust `core/model_operations/operation_applier` engine. No TypeScript validator/applier substitutes for its semantic judgment.

Single changes use typed target identity and before-state/unit/provenance checks. Rich replacements use `update_support` on `configuration`, `set_field` on `temperature_points`, and `update_load` on `equivalent_static.wind.exposure`; canonical JSON before-state and explicit nested quantities bind whole-record edits. Shared sections use `assign_section`/`detach_section`; guarded removals use `delete_material`/`delete_section`/`delete_component`. Components still use `insert_component_symbol`, not a new `create_component` change token. The binding executable taxonomy is `core/model_operations/operation_applier/src/lib.rs::check_kinds`, including `split_pipe_run` and `transform_pipe_run`; broader schema tokens do not establish coverage.

Batch route: form or offline file → `App.tsx::handleQueueOperationBatch` freezes original model, hash, revision and exact submitted members → `BatchReviewPanel` explicit Validate → Rust `atomic_batch.rs` strict preflight and temporary same-applier execution → per-member deterministic diff → explicit Apply → one committed returned model, receipt and session checkpoint. A failed later member publishes no partial model. App checks the current hash/revision before and after asynchronous execution and rejects mismatched batch/basis or application-shaped validation results; withdrawal/model replacement invalidates stale callbacks. Validation alone creates no acceptance. Pending batches never mutate the model.
