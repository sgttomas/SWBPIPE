## Ruling

**CAND-5 is adopted as a small documentation tranche (P4):** name the
currently absent-and-unacknowledged special domains in `docs/PRD.md`
(non-goals and/or open-questions surfaces, wording chosen in-tranche) so
their absence reads as a recorded decision rather than an omission:

buried pipe / soil springs · jacketed pipe · FRP / orthotropic materials ·
slug / two-phase forces · snubbers · fatigue cycle counting · first-class
nozzle-flexibility objects · mitered-bend and stepped-reducer formulations ·
expansion-joint hardware kinematics (tie rod / hinge / gimbal) beyond
metadata.

Naming an item is a scope statement only — it neither schedules nor
forecloses future work; promoting any named item into scope later follows
the governed scope-change path (`D-21`/SCA precedent).
