## Selected effect

Option O-B is selected faithfully:

1. Add a new explicit user-entered shear-modulus G quantity to material
   temperature points.
2. Apply the existing `DEC-077` method to G: exact-id basis selection remains
   available; declared solve temperatures use linear interpolation only
   between qualifying adjacent user-entered points; every derived G value
   names both source points and the declared method in provenance; and the
   solve blocks rather than extrapolates when a qualifying bracket is absent
   or the temperature is at or beyond the stored range edges.
3. Preserve the user-entered base G when no temperature basis is selected.
   Under a selected exact-id or interpolated-temperature basis, implementation
   evidence must establish consumption of the explicit temperature-point G
   values without a hidden base-G fallback.
4. Apply the same independent hand-calculation, benchmark, unit-bearing
   authoring, mutual-selection, provenance, missing/invalid-input, and
   edge-blocking evidence bar used for `DEC-077` before claiming the ruled
   behavior implemented.

This ruling is codified as `DEC-092` in

## Verified current implementation boundary

At codification time, the live material temperature-point input carries
temperature, elastic modulus, and thermal-expansion coefficient fields but no
temperature-point shear-modulus field. The live modulus-basis resolver still
clones the material's user-entered base G for both exact-id and interpolated
E/alpha bases. Those facts are current implementation evidence, not the ruled
end state.
