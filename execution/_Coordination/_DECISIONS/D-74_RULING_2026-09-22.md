# D-74 ruling — the project license is MIT

## Owner act

The owner answered a question about the license in a session on the SWBPIPE
websites, having been told that `LICENSE.md` and the user guide still named
`PolyForm-Noncommercial-1.0.0` while the product was being described as MIT.
The first item of the owner's reply, verbatim:

```text
1.  We're going MIT, you can make the necessary changes now.
```

Custody: extracted from the session's stored transcript; UTF-8, no trailing
newline; SHA-256 `6269e8e400b91586e35ac6070ca6b84de4434ff797f9a5ab151e0e75dd9597d2`.
This is custody of the host's stored transcript bytes, not original transport
bytes. Recorded by Claude Code (Claude Opus 5.5), working as HELP_HUMAN for the
owner outside the paused piping loop.

The owner's reasons, from the same message: the product is meant to be
ubiquitous and accessible to licensed engineers and other professions; the
business is consulting and teaching, not selling the software.

## Adopted bounded effect

1. `LICENSE.md` carries the MIT license text, identical to the repository root
   license.
2. The live documents that stated the former license now state `MIT` with this
   ruling as the basis: `CONTRIBUTING.md`, `docs/README.md`, `docs/DIRECTIVE.md`,
   `docs/CONTRACT.md` (OPS-K-GOV-1), `docs/PROFESSIONAL_BOUNDARY.md`,
   `docs/IP_AND_DATA_BOUNDARY.md`, `docs/AGENTIC_DEVELOPMENT_WORKFLOW.md`,
   `docs/report_notice_template.md`, `docs/user_guide/index.md`,
   `docs/contributor_guide/index.md`, `governance/*`, and the two export panels'
   `source_license` context strings.
3. SOW-001 reads "a free and open-source piping stress analysis platform" and
   SOW-001/SOW-048 notes record the new selection, in both
   `docs/_Registers/ScopeLedger.csv` and `SOFTWARE_DECOMP.md`; codified as
   `DEC-112`.
4. Historical records keep their words: run records, reconciliation evidence,
   DAG snapshots, prior scope-change postimages and deliverable working files,
   including the issued DEL-01-01 files, which change only on their own change
   path. A later reconciliation should note the license change against
