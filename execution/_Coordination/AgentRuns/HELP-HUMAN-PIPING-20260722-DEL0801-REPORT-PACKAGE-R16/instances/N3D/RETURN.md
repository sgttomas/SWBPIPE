A real loaded-pack run can instead return `RULE_INPUTS_INCOMPLETE`; the live panel keeps the pack and run privately, lifts only the aggregate (`apps/desktop/src/features/rule-check/RuleCheckRunPanel.tsx:321-346,553-582`), and its focused test demonstrates an authored active pack whose run result is `RULE_INPUTS_INCOMPLETE` (`apps/desktop/src/features/rule-check/RuleCheckRunPanel.test.tsx:353-383`).
