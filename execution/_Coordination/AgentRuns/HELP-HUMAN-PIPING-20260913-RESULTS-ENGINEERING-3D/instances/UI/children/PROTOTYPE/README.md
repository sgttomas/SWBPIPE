# Offline engineering workspace design

Open `prototype/index.html` directly in a browser. The entry uses local CSS/JS and original projected SVG geometry; no server, package installation, external font or network is needed. This is a personal design candidate derived from the approved V3 direction and source-qualified CONCEPT_V1/INTERACTION_CONTRACT_V1. It is not adopted normative product behavior or engineering acceptance. The persistent **SIMULATED DESIGN PROTOTYPE** badge applies to every state, input, operation, quantity and result.

The screen keeps all seven command groups visible, a shared typed model tree/canvas selection, a focused authoring rail with pinned Add/Cancel, and a resizable Review/Results dock with pinned simulated Apply. Source-shaped JSON is available in disclosure and State / intent. `window.prototypeInspect()` returns a copy for witnessing; it has no setter. All revision tokens are visibly mock tokens, never cryptographic proof.

## Three exact walkthroughs

1. **Route:** Build → Route pipe. Select From N5; choose New endpoint; choose XY/XZ/YZ and applicable Free/axis; choose m/mm/ft/in. Click a blank canvas plane to capture into the same XYZ form. Drag beyond 4 CSS px to orbit without authoring; pointer coordinates use inverse SVG screen CTM and explicit 12-significant-digit precision. Enter XYZ (e.g. 6.2/1.8/3 in m), outside diameter 114.3 and wall 6.02 in mm, M-DEMO, explicit Y 0/1/0 and visible invented provenance. Enable continuation. Add → Review; expand exact payload with create_node + connect_pipe_run; Validate simulation → Apply simulated draft. One atomic mock checkpoint appears. Continue uses that route's matching applied endpoint and retains entered units/section/source; enter the next explicit XYZ (no invented automatic coordinates). Cancel that draft; Undo/Redo each move one checkpoint. Scenario controls can hold busy, mark stale or withdraw generation; Complete held mock callback after Cancel produces a named ignored-generation message, never restored review or model apply.
2. **Place/edit:** Tree Node N5 → Build → Components. Choose Valve, node N5, primary P5 and secondary P4 explicitly; provenance is visible invented demo input. Symbol insertion → Add → Validate simulation → Apply creates one mock symbol. Finite insertion instead produces `FINITE-INSERT-UNAVAILABLE` and no apply. Supports → Restraint / anchor; select node and support identity, all six explicit Anchor DOFs and your invented provenance; blank stiffness stays missing. Add → Validate simulation → Apply. Spring/nonlinear tools expose additional required values without fabricated catalogue data. Edit → Copy / rotate / mirror → P5 → Add produces `ATTACHED-TRANSFORM-BLOCKED` with unchanged history; PFREE is an explicitly unreferenced invented simple run. Properties → Edit pipe properties → P5; change wall to 7.1 mm and enter provenance; exact `set_field` before/after is reviewed and explicitly applied. Split retains original pipe identity on first half and creates one new second-half identity.
3. **Results:** Results → Run simulated solve produces invented Current rows and a clearly scaled illustrative overlay. Details on a row link typed entity selection and expose quantity/kind/component/unit/dimension/frame/location/run basis. Rotation is rad/angle; only explicit ratio rows are ratios. Work residual is diagnostic N*m, unclassified by this prototype's dimension policy. Change wall through the property flow: Current becomes Unavailable, overlay off. Results → Reopen saved prototype becomes Historical, acceptance UNKNOWN, excludes Current overlays/rule checks/readiness. A new simulated Current solve is required to restore Current. Scenario controls select blocked/nonconverged/cancelled outcomes with named diagnostics and no solved export. Local storage keeps only this invented prototype example where available; it does not reproduce production saved/hash/checksum behavior.

## Keyboard and density

Tab reaches commands, tree, task, Review/Apply and scenario diagnostics; visible focus rings show the active control. `/` focuses command search, `R` opens route, `F` fits view, Ctrl/Cmd+Z and Shift+Ctrl/Cmd+Z move mock history. Enter on canvas moves focus to typed authoring; tree and coordinate controls provide keyboard alternatives to picking. Escape withdraws the draft, or closes the scenario dialog and returns scenario-button focus. The dock separator supports ArrowUp/ArrowDown resizing.

Comfortable uses 14px body, 32px controls, 232/292px rails and 224px dock. At 1024px it uses 194/272px rails and 214px dock. Compact uses 12px body, 26px controls, 194/252px rails and 202px dock. The same tasks and command mappings are available in both. Rails and dock scroll internally while Add/Cancel/Apply remain pinned. Tree can be collapsed for more canvas space. View changes (camera, density, units, selection) never create model history.

The six `wireframes/workspace-{size}-{density}.svg` files contain editable text, controls and original pipe vectors with the same density/layout constants and frozen route state. Edit them in a vector editor or regenerate with `python3 write_wireframes.py` (pure asset writer). Regeneration of capability/source maps is `python3 write_maps.py`. Source asset rewrite scripts document pre-freeze formatting/semantic refinements; they are not product runtime and should not be repeatedly applied to a final candidate.
