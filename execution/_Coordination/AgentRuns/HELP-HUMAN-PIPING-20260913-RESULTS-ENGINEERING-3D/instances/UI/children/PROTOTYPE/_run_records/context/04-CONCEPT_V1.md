# Professional authoring concept V1

Use a restrained engineering workstation with neutral graphite header, warm-white surfaces, blue active tools and clear green/amber status. Canvas is the central visual object: original isometric piping, grid, three-axis orientation and selected geometry; no decorative marketing illustration. A persistent two-row command band keeps Build, Supports, Properties, Loads, Edit, Select and View, Review visible and complete. Left model tree; right contextual Route/Component/Properties rail; bottom resizable review/results dock. Plain labels accompany icons. Display SIMULATED DESIGN PROTOTYPE persistently, with a separate small Mock engine state label. No backend/hash-proof claim.

Compare Comfortable (14px body, 32px controls, 232/292px rails) with Compact (12px body, 26px controls, 194/252px rails), same exact three tasks and functionality. Responsive rails can collapse at 1024px, but focused task rail and canvas remain accessible. At 1024×768 no body overflow or clipped Apply/Cancel; 1280×800 and 1440×920 show progressively more spatial context. Fit model, iso/front/top, orbit via pointer drag, select entities via canvas/tree and keyboard/typed alternatives are reviewable. Camera/selection remain view state, never model history.

Route journey: start with invented editable geometry and explicit entered dimensions. User chooses From, existing/new endpoint, XY/XZ/YZ, Free/applicable axis, mm/m/ft/in, typed XYZ or pointer plane placement. Pointer and typed input feed one draft. Add freezes existing operation-shaped intent, Review displays exact payload, then Apply produces one simulated atomic checkpoint. Continue advances From only on its own matching apply. Busy/stale/cancelled controls are injectible and inspectable. Cancel draft does not alter model; undo/redo invalidates current results. Retain current 4 CSS px click/drag threshold.

Component/support journey: select Node/Pipe, explicit incident-pipe roles plus component kind or support DOFs/stiffness/provenance. Place symbol maps to insert_component_symbol; support to create_support/update_support; property edit set_field. Finite insertion and attached transform explicitly blocked/backfill; unreferenced transform maps to transform_pipe_run and split to split_pipe_run. No implied connected-network geometry semantics. Missing engineering values stay missing.

Results journey: simulated solve produces explicitly invented Current examples; rotations rad/angle, only real ratio rows classified ratio, work residual diagnostic N*m (no invented energy dimension policy). Edit invalidates Current; reopen saved prototype record displays Historical, acceptance UNKNOWN, excludes current overlays/rule checks. Show precise quantity/kind/unit/dimension/frame/location/basis fields. Never derive semantics from ID. Provide mocked blocked/nonconverged/cancelled outcomes with clear diagnostics and no successful export.

Every normative vocabulary row 1–24 is discoverable via grouped tools/search, each with existing typed operation mapping and known scoped limitation. R1 renumbering/R2 snubbers/R3 cold spring remain labelled ROADMAP without executable semantics. Generic nonjourney commands may show structured contextual inspector and payload mapping; mark any simulated/backfill area visible rather than fake completion. Existing operation service names are reference mappings; all prototype application is mocked.
