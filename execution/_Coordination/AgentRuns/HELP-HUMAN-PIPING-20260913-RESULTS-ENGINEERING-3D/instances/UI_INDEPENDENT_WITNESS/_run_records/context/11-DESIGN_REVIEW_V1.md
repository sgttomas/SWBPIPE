**Recommend Comfortable as the default**, with Compact an explicit user preference. This is manager judgment from the recorded same-task comparison, not independent usability acceptance. At 1024×768, Compact adds only 20px of canvas width and 12px height; that does not justify imposing smaller text. At larger sizes it recovers 78px width and 22px height, useful for experienced users. Comfortable favors form readability, wider fields and 32px controls; Compact uses 26px controls and denser tree rows. Both retain internal scrolling for long route forms and result details. At 1440×920, both fit the property form; at 1024×768, fixed Add/Cancel and Apply remain reachable while the form scrolls.
