# Screenshots for slice C1E (the edge line)

The viewport region at 1:1 in device pixels (794 x 580 CSS pixels; 1588 x 1160 at ratio 2), window 1440 x 920, headless Chrome with hardware WebGL, taken through the host's browser lock on port 5186 by a throwaway script kept outside the repository. Every picture is of the final build of this slice, served from a copy outside the repository (its `index.html` has SHA-256 `0933b9d42a30898a44b3c582ebd56359a1f8b2be4b0299598ad06f01259044d1`). The sample project is the product's start-up model unless a row says otherwise. Labels and authored loads are switched off so that the line can be read. The console held no warning and no error in any state.

The "before" pictures are `../C1A/` (its README lists the states).

Where the data shows no such thing: the sample project has one outside diameter, so it has no change of diameter. The two benchmark fixtures have many, but their pipes are shorter than their node spheres and every joint is under a sphere, so no step can be read from either side; the two `diameter_change` pictures per theme show that. For the same reason the open end of a pipe is under a node sphere in every model the product opens today.
