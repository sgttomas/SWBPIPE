# Screenshots for slice C1, first part (C1A)

The viewport region at 1:1, device scale factor 1, window 1440 × 920, canvas 794 × 580 (529 × 580 while routing), headless Chrome with hardware WebGL, taken through the host's browser lock by a throwaway script kept outside the repository. Files named `before_*` were taken by the child C1A-PALETTE from the unchanged tree at `de348f2cd683165afcf6c399268b285f2ccb369a`. The others show the slice.

Eleven of the seventeen "after" images are the child's own and are byte-identical to the manager's re-run on the merged head `9e2fe2826dfe9506d7adc558e8edad658944e9ed`. The six marked *refreshed* replace the child's: the manager changed one row of the role table after the child returned (the deformed overlay from `canvas.deformGhost` to `canvas.vector`), and the overlay is visible in those six states. The child's return lists the hashes of the six it took; those files are superseded and are not kept.

States: `model` (grid, loads, labels on); `model_nolabels`; `selected_actual_od` and `selected_schematic` (`pipe:P-110` selected); `deformation_selected` and `deformation` (after the sample solve; the second with `support:S-100` selected); `route` (a route started from `node:N-140`, hover ghost shown, overlay still on); `live_1` to `live_3` (one page, `pipe:P-120` selected, switched light to dark to light with no reload).
