# B3 independent review checklist

Drafted by ROOT under the adopted continuation; attach to a candidate-bound
fresh-context brief before review. This is an ad hoc checklist, not a reusable
workflow or new acceptance authority. Requirements come from the approved
package, implementation handoff and amendment 1.

- Cover the complete B3 diff from main, including inherited checkpoints, rather
  than just the continuation edits. Verify true candidate/base, changed paths,
  test evidence and declared deferrals. Check C2 integration and project-handler
  fixes survive. Findings in returns are not proof of their own repair.
- Shell structural checklist against the named frames/specification: 48 px
  toolbar, 56 px rail, 44 px unavailable agent strip, 24 px status bar; per-stage
  Table/Model/Both and Review restrictions; mounted panel state; explicit
  disabled reasons and pointer equivalents for keys. Distinguish pane from
  drawn canvas and actual native geometry from browser runtime geometry.
- D1 keeps overlay: measurement/readout, scale, DOM marker AND painted orientation
  frame clear of strip. Scope the named placement-witness change to overlay
  clearance while preserving crop size, pointer ownership and axis/picking
  semantics. Expanded narrow drawer is in flow with operable splitter and
  180–600 px reachability. Existing protected floors/endpoints remain.
- D2 lends table width first down to 320 px, with 220 px canvas minimum; restore
  table width from remembered split when inspector closes. Default 1440: table
  437, canvas 603, inspector 300. Default 1280: 349, 531, 300. Verify real drawing
  width and geometry after routing portal, not arithmetic alone. Camera/picking
  must follow screen-position changes. Describe genuine deferred B5 states.
- D3 replaces only Both-view canvas/table dominance with ruled allocation checks;
  original drawing measurement, relevant unconditional 35% floors, canvas versus
  inspector and overflow remain. No unrelated relaxed timeout, skip, tolerance,
  oracle, fixture or frozen value can masquerade as a structure move.
- Routing controls have one state and operation path when portalled. Arming opens
  inspector; disarming restores prior state, respecting intervening human action.
  Check pending intents, view changes and selection changes. No duplicate DOM
  control or hidden unmounted state is used to fake reachability.
- Single engineering mutation route, exact solve basis/generation gates, Current
  and Historical distinctions, overlay/chip eligibility, apply/review, undo/redo
  and save/reopen. Check interrupted, failed and superseded requests.
- Native menu command/state and accelerator routes connect to the same sink as
  the shell; window minimum and project identity/title bar in actual Tauri.
  No browser class substitutes for native witness. State whether later B3A/B3B
  features stay separate. Inspect actual src-tauri/frontend connections, not
  just parallel component tests.
- Keyboard/focus order, visible focus, accessible name/role/state, target size
  for touched controls. Contrast criteria are explicitly deferred, never claimed
  passed. Structure-only fidelity review is separate from code review.
- Connected journey evidence checks resulting model/history/standing, and records
  environment/candidate/actions/expected/observed with reproducible raw evidence.
  Cover cancellation, invalid input and recovery as operable. Explicitly list
  unavailable scenarios. PDU-045/PDU-046 remain held.
- Rendering construction, resource ownership, persistent renderer, picking
  foundation and frozen instrument files are preserved unless separately
  authorized. D-72 is not qualified by this slice's ordinary checks.
- Status, evidence and claims remain separate: no deliverable/DAG reconciliation,
  usability acceptance, performance qualification, product release or owner
  personal-review claim. Check provenance and actual model/parentage records.
