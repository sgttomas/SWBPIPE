## Alternative and reversal

Measured dependency is immediate DOM row movement while native Undo must survive. Deferring sorting is a viable alternative: on editor start return to input order, label requested sort deferred throughout editing, and apply latest complete projection on exit. Merely freezing the old sorted view during invalid/pending basis would violate required immediate stable-input-order fallback. Full deferral changes live projection/navigation behavior and requires different copy/oracles; stable host preserves those current semantics at the cost of measured positioning/clipping/focus code. Resize alone and every virtualization event are not claimed to require a host. Reversal is remove Materials persistentEditor opt-in and host/position styling, either restoring the documented Undo limitation or substituting explicitly agreed sort deferral. No canonical model/history changes follow either presentation reversal.

Final lifecycle repair: geometry measurement continues through inert ancestry while parent inert still blocks interaction. Display-hidden or zero-layout ancestors retain last usable placement; explicitly inactive Materials surfaces still hide. Initial focus guard remains hidden/inert-aware, so page return does not steal focus. freeze4 and browser-inert-repair.json contain the final exact source and measured visible/aligned unchanged editor with rail focus in both profiles.
