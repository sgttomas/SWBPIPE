# Independent repair references and scope

The tests use explicit synthetic local inputs, not catalog values or material-standard defaults. The scope is linear, small-strain, prismatic circular-annulus mechanics with ideal fixed root, positive linear spring, ideal unilateral gap and/or prescribed constant nodal force. There is no pressure, yielding, ovalization, warping restraint, large displacement or code-stress claim.

## Co-located support equilibrium

For length L=2 m, OD=0.168 m, ID=0.154 m and E=200 GPa, direct section integration gives A=pi(OD²-ID²)/4 and k_bar=EA/L. The gap closes at g=0.05 mm=0.00005 m. A separate spring has k_s=100 MN/m; a separate constant-effort force is C=1500 N (only one parallel control at a time). Each is applied at the axial tip DOF. Force balance and compatibility give u=min((F+C)/(k_bar+k_s),g), root reaction=-k_bar*u, spring reaction=-k_s*u, and contact reaction=(k_bar+k_s)*u-(F+C). F=1000 N leaves contact open; F=50000 N closes it for both controls. Contact reaction is nonpositive, u never exceeds g. The published root/spring rows are magnitudes, so those two assertions compare positive magnitudes; the nonlinear contact row is signed and checks the negative reaction directly. The consumed constant-effort load row must equal +1500 N. These separate checks imply signed force balance without mistaking a scalar reaction magnitude for a signed vector.

This axial compatibility/equilibrium reference is independent of solver output and does not depend on beam transverse shear assumptions. Same-record spring/contact overlap remains a blocking contract because current per-support attribution replaces the spring component with the contact residual. A separate spring identity has its own -k_s*u row and is supported. Rigid/contact overlap remains blocked. A constant-effort restraint token is its applied-force direction; it does not prescribe displacement.

## Skew typed end couples

The proper orthogonal rotation R has columns e1=(1,2,-2)/3, e2=(-2,2,1)/3, e3=(2,1,2)/3. The member tip is L*e1, and its supplied local y reference is e2. Each local-axis couple +/-250 N m is authored as three rotation_x/y/z records containing the global components M_global=R*M_local. Direct annulus integration gives I=pi(OD^4-ID^4)/64 and J=2I. With E=200 GPa and G=77 GPa, theta_local=M*L/(EI) for bending or T*L/(GJ) for circular torsion; theta_global=R*theta_local. The independent tip translation is u_global=L²/(2EI)*(M_global cross e1). Local i-end moment action is -M_local, j-end is +M_local, and resultant support force is zero.

The unloaded span has V=0, so transverse shear deformation contributes zero to this end-couple reference; this restricted control does not require an approximate thin-wall section or a shear-factor choice. The signs follow right-hand vector products. Rotation result rows round to six decimal places (rad), displacement rows to six decimals (mm); new assertions allow their half-unit rounding plus small floating-point allowance. Existing protected tests and tolerances were not changed. Member end-action checks cover available signed moment outputs, while full signed support moment publication remains a programme limit.
