## Work-conjugate scaling

For each connected mechanical component, let physical generalized displacement be `u=[translations in m, rotations in rad]` and generalized load `f=[forces in N, moments in N*m]`. Choose a finite positive component characteristic length `L_c`, e.g. maximum physical element length, retained in evidence. Centre coordinates before rigid-mode calculations. An isolated supported node can use an explicitly recorded 1 m reference length; an unsupported isolated node is not repaired by that choice.

Define diagonal `D` with `L_c` for translational DOFs and 1 for rotations. With `u=D q`, every component of `D^T f` has energy units and

```
u^T f = q^T (D^T f)
u^T K u = q^T (D^T K D) q.
```

Thus scale by congruence, not independent row normalization. After exact constraint elimination, define `H=D_f^T K_ff D_f / E_c` and `g=D_f^T(f_f-K_fc u_c)/E_c`, where `E_c` is a finite positive energy reference, conveniently the largest positive diagonal of `D_f^T K_ff D_f`. Compute products/divisions with exponent-aware scaling so forming the reference does not overflow or erase subnormal inputs. Retain the original physical matrix separately.

For positive diagonal entries, equilibrate symmetrically: `S_ii=1/sqrt(H_ii)`, `A=S H S`, `b=S g`, solve `A y=b`, then recover `u_f=D_f S y`. A deterministic nearby radix-power variant is acceptable if its choice is recorded. Report both physical length scaling and the final equilibration factors. Zero or negative diagonal is a diagnostic requiring classification; replacing it with an arbitrary floor would add fictitious stiffness. Overflow/underflow that changes a nonzero matrix term is an unresolved numerical range failure, not zero stiffness or a successful solve.

This preserves energy and inertia under nonsingular changes of variables. Ideal unit-diagonal equilibration cancels simple diagonal unit changes; it does not cure dependent rows or add missing restraints. Congruence and preservation of inertia follow from the quadratic form; [Schultz's primary lecture proof](https://palmer.wellesley.edu/~aschultz/w10/math416/coursenotes_and_handouts/coursenotes_100422.pdf) gives the general result. [LAPACK DPOEQU](https://www.netlib.org/lapack/double/dpoequ.f) supplies the symmetric diagonal-equilibration construction. These references justify the method, not a product acceptance tolerance.

## Stability, inertia and explainable classifications

Use four distinct outcomes: `stable_resolved`, `mechanism_identified`, `inadmissible_negative_energy`, and `numerically_unresolved`. Sensitivity is an additional flag. None is a professional acceptance category.

1. Build the mechanical connectivity graph from actual element/constraint contributions, not node proximity or a global restraint count. For each ordinary objective connected body construct the six rigid columns using `r_i=(x_i-x_c)/L_c`: dimensionless translation at node i is `t + omega cross r_i`; rotation is `omega`. Restrained/support-direction rows applied to these columns give the rigid-mode restraint matrix `B`. Positive grounded spring directions count geometrically, independently of stiffness magnitude; only actually active contact constraints count for a selected active state. A rank deficiency identifies a remaining rigid motion. Report the component, support IDs, null-vector rigid translation/axis and contributing node/DOFs. Potential future contacts may permit a nonlinear attempt; they cannot certify the current state.
2. Use rank-revealing QR/SVD of this small six-column, row-normalized matrix. Record singular values and the rank uncertainty band. A small singular value within floating-point uncertainty is `numerically_unresolved` unless an independently verifiable geometric null vector identifies the mechanism. This precheck does not detect every internal hinge/connector mechanism; the reduced stiffness gate remains necessary. With multi-point constraints/rigid offsets, form admissible motion by the actual constraint map, not only a list of eliminated DOFs.
3. The current passive, small-displacement elastic stiffness plus positive springs must be symmetric positive definite on unconstrained DOFs. Check symmetry on dimensionally scaled entries before the sparse path can ignore a triangle. An asymmetry exceeding the recorded assembly roundoff budget blocks as assembly/interface inconsistency. Any explicit symmetrization within that budget must be recorded, and residuals still use the retained original equations. A future physically nonsymmetric tangent needs a different explicitly typed contract.
4. In both modes, require a successful symmetric positive factorization of `A`. Sparse LDL may supply `C=L sqrt(D)` only when every D is positive. Dense scrutiny must obtain equivalent symmetric evidence; successful row-pivoted LU alone is insufficient. Negative/near-zero sparse factors must not be silently rescued by a finite dense displacement. Dense fallback is allowed only when it also satisfies the shared gate and explains the sparse numerical/storage failure.
5. A positive computed factor proves positivity of the nearby factored matrix, not automatically the original one. A concrete sufficient certificate is available without an arbitrary global pivot ratio: retain `E=A-C C^T`; compute an outward-rounded upper bound `delta >= ||E||_infinity` including residual-evaluation roundoff. Bound `p >= ||C^-1||_infinity` and `q >= ||C^-T||_infinity`. For a triangular C, inexpensive nonnegative substitution bounds are `z_i=(1+sum(j<i)|C_ij| z_j)/|C_ii|` and the corresponding backwards recurrence; take their maxima, with outward rounding at operations. If `p*q*delta < 1`, then `||C^-1 E C^-T||_infinity < 1`, which certifies SPD of the original represented symmetric A. This is conservative; failure to certify is `numerically_unresolved`, not evidence that a compliant physical model is a mechanism. A sharper verified inverse/eigen analysis can resolve such cases without loosening the inequality. Include scaling roundoff when extending the certificate to the pre-scaling symmetric canonical stiffness. A nonsymmetric original assembly cannot itself be called SPD: its measured skew remains separate evidence, and its full equations remain the residual target even when a bounded symmetric projection is used for factorization.
6. A diagnostic symmetric pivoted LDL with 1x1/2x2 blocks, or a symmetric eigensolver with reconstruction/orthogonality error bounds, can classify unresolved/negative cases. Count positive, negative and zero directions from symmetric D blocks, not LU diagonals. [LAPACK DSYTRF](https://www.netlib.org/lapack/double/dsytrf.f) documents that block structure. For a claimed negative-energy mode, retain a mapped vector `v` and show `v^T A v` is negative beyond its evaluation/error bound. Near-zero directions without a physical null proof remain numerical uncertainty. Record estimated inertia as estimated unless error bounds establish the original-matrix claim.
7. Estimate reciprocal condition number in the declared scaled norm for sensitivity reporting. A pivot ratio is not a condition number. An estimator must retain its name and status; estimates do not become rigorous certificates. A small backward error plus large condition number can coexist with substantial displacement error. [LAPACK's error-measure definitions](https://www.netlib.org/lapack/lug/node75.html) distinguish these quantities.

The sufficient SPD certificate needs rigorous triangular inverse **upper bounds** p and q plus the factor residual bound delta; it does not need an rcond estimator. rcond is optional advisory evidence, never a substitute for those bounds. Outward control includes the multiplication `p*q*delta`, divisions and accumulated sums, not just one final `next_up`. If implementation cannot establish upper bounds under its arithmetic, label the evidence an estimate and do not emit `stable_resolved` on the strength of that estimate alone. A failed conservative certificate may route to sharper independently verified scrutiny. Until resolved, the publication outcome is `numerically_unresolved`; ordinary finite LU fallback cannot override it.

No support should be fabricated to make a matrix invertible. No diagonal regularization/penalty should silently convert a blocked state to `MECHANICS_SOLVED`. A zero-load mechanism remains a mechanism even though `u=0` has zero residual.

## Original-equation residual and backward error

Freeze the physical assembled `K_original`, total consistent `f_original`, case/modulus basis, boundary values and DOF map before scaling, ordering or elimination. For the recovered full `u`, including nonzero prescribed DOFs, compute

```
r = K_original u - f_original.
d_i = sum_j |K_original[i,j]| |u_j| + |f_original[i]|.
eta_c = max over free i of |r_i| / d_i.
```

At a free DOF, r is equilibrium error. At a constrained DOF, r is a reaction, not a residual to force to zero. Preserve signed force and moment residual components and maxima separately in N and N*m, with node/DOF identities. Check imposed displacement compatibility separately. For nonlinear selected states include the actual same-state applied friction/affine load and boundary values, and separately check support constitutive/complementarity inequalities; a changed-support count is not force equilibrium.

`eta_c` is componentwise dimensionless and invariant in exact arithmetic under positive diagonal unit/unknown scaling: each row numerator and denominator transform by the same factor. It avoids comparing a force residual with a moment residual. Also report the normwise metric on a declared work-conjugate scaled system, `eta_inf=||A y-b||inf/(||A||inf ||y||inf+||b||inf)`, but label its coordinate/scaling basis. The componentwise formula and use of the unfactored matrix are consistent with [LAPACK DPORFS](https://www.netlib.org/lapack/double/dporfs.f). Implementation must not compute either metric from already factored rows, LU back-substitution remainders, rounded results or a different assembled sparse model.

Evaluate dot products with compensated/pairwise summation or more accurate residual arithmetic and a recorded evaluation bound; retain absolute term sums before cancellation. Coalesce duplicate sparse contributions consistently, or compare direct-entry assembly with the original model action before solving. A residual of the sparse matrix alone cannot detect an omitted spring/element shared by both its solve and residual helper. Unit/sign/load/assembly correctness additionally requires independent physical equilibrium/reference checks; backward error certifies the represented equation, not its engineering model.

**Selected acceptance metric:** gate on a verified upper bound `eta_c_upper` for the true componentwise backward error of the retained represented equations, not the floating-point estimate alone. For each free row, establish `|r_i| <= |r_hat_i|+e_i` with outward arithmetic, and a conservative positive lower bound `d_lower_i <= d_i`. Then form `eta_c_upper=max_i upper((|r_hat_i|+e_i)/d_lower_i)`. Obtain denominator bounds from bounded positive product/sum accumulation with exponent scaling as needed; apply outward control to the numerator addition and ratio too. Merely publishing an evaluation-error estimate while testing an underestimated `eta_c` is insufficient. If no finite reliable bound is available, or the denominator lower bound is zero without an independently established exact-zero row, classify the metric as unresolved. An estimated `eta_c` may also be reported, but must never be labelled certified or used to override the bounded gate. This qualifies residual arithmetic; it does not alter the prospective factor-64 reserve or establish forward-error/physical-model accuracy.

Zero/subnormal rules are explicit: a truly zero row denominator and zero residual contributes zero; nonzero residual with zero denominator fails. Avoid adding a fixed N or N*m floor to every row. Rescale a tiny row locally by an exact power of two for residual evaluation or use a dimensionally scaled safe-minimum guard with recorded status. If nonzero information has already underflowed or a denominator cannot be represented reliably, return unresolved; do not report a spuriously perfect residual. Reject any nonfinite input, factor, recovered value, residual, scale or error estimate before successful publication.
