## Stress quantities and factor scope

For an isotropic circular annulus with bending Z=I/ro, define signed axial membrane `a=Nw/As` in exact pressure mode (generic N/As when no pressure correction is needed), bending amplitude `b=hypot(My,Mz)/Z`, outer normal extrema `sigma_plus=a+b`, `sigma_minus=a-b`, and maximum absolute normal stress `max(abs(sigma_plus),abs(sigma_minus))=abs(a)+b`. Keep torsional shear `tau=T*ro/J` separately, including sign; pure torque therefore has zero normal stress and nonzero torsional shear. Preserve hoop/radial stresses and surfaces separately. These are named elastic stress quantities, not a piping code stress or an allowable ratio. No von Mises, Tresca or code-category formula is silently substituted into the headline.

Flexibility k changes the element compliance where qualified. It never multiplies recovered stress. User SIF inputs affect only their declared bending-direction components in a declared component/station frame; axial, pressure membrane and torsion are not multiplied without a separately specified user rule. With signed in/out bending moments and factors ii/io, a named user-intensified bending measure is `hypot(ii*Mi,io*Mo)/Z`; it is not an adopted code formula. For the existing scalar user SIF, the first supported successor explicitly declares equal factor on both bending directions and labels that interpretation in the result. No code-derived factor or geometric default is invented. Existing fitting/pipe association must be validated; ambiguous frame/branch/end coverage withholds the intensified result with a targeted diagnostic. Do not guess frame directions from the result being measured.

Retire `component_user_stress_multiplier_review` from fresh mechanical sum/subtraction and new engineering summaries. Its historical meaning remains verifiable. Replacement row kinds state quantity and factor basis; the raw result/derivative semantic version and all consumers change together. A source test that asserted i*k is preserved as old-contract history, with a independently checked successor showing fixed recovered moment → stress independent of k. Actual changing k can redistribute moments in an assembled structure; that is not the same assertion.

For straight uniformly loaded spans, the old eight-signed-quadratic extremum routine is tied to `abs(a)+abs(by)+abs(bz)` and cannot be retained with the new norm. Implement the independently specified stationary/root-and-boundary treatment in `STRESS_REFERENCE.md`, including axial zero crossings, zero bending vectors, load-span boundaries and candidate validation after squaring. Qualified global maxima require extrema treatment over the actual element domain. For curved rows with only sampled stations, label the maximum as sampled and do not assert an exact element maximum; analytic/adaptive curved qualification stays a separate explicit M37 consequence.

## Combination semantics

Each result set declares one of: solved equilibrium state, linear compatible-state combination, signed state difference, or selection envelope. Source case/state IDs and their basis are mandatory. Existing `mechanics` combination may qualify as a new linear equilibrium result only when operand geometry, supports, prescribed-reference state, element constitutive matrices and pressure formulation are the same, and constituent load accounting is compatible. Compare actual per-element selected stiffness/material/section and constraint basis, not merely a human label. Distinct E/nu distributions invalidate that qualification even if a model-level label matches. Never scale reactions by a single E ratio to repair mixed-basis models.

For any nonlinear operand, first-tranche `mechanics` superposition is blocked as an equilibrium combination with `NONLINEAR_COMBINATION_REQUIRES_SOLVE`; solving the combined physical loading is the appropriate route. Identical source active-set labels alone are insufficient because the summed state can violate gap/friction admissibility. Preserve each original solved state and diagnostic; do not discard valid independent cases because one requested combination blocks. The combined-load solve route must share the actual physical load contributions once (especially persistent support preloads/constant effort); it is a following implementation requirement, not closed by the diagnostic.

`result_state_subtraction` remains signed minuend-minus-subtrahend at matching physical locations and frames, retaining both support states and basis identities. It is a difference of states, not an additional equilibrium solve. Algebra on displacement/action differences remains useful across differing material states when explicitly identified. Stress-range recovery requires a selected compatible stress/material/section reference basis; until provided, withhold the range summary with `STRESS_RANGE_BASIS_REQUIRED`, while retaining the action difference. Do not call it EXP or code-qualified by default.

Perform allowed sum/subtraction on signed section actions, displacement components and support actions, then recover norms/stress measures. Do not combine magnitudes, absolute extrema or pre-intensified scalar summaries. A selection envelope may choose an already recovered scalar maximum/minimum and must retain the governing source case/station. Componentwise envelope vectors must not be passed off as a simultaneous state or fed to a stress recovery as if all components co-occurred. ABS/SRSS, nested combination graphs and code categories have separate designs and are not introduced implicitly here.

Report per-case maxima and an overall maximum over explicitly comparable valid quantities, each with governing case, element/node/station, quantity, basis and sampled/exact status. Preserve requested-but-blocked case/combination counts; an available-subset maximum is not an all-requested-results maximum. Case order must not affect the result. Never compare different normal/equivalent/code quantities or silently omit incompatible modulus cases from an unqualified headline.
