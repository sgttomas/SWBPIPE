### RV41-1 — account and admit newly reachable ordinary work before continuing a failed invocation

**Blocking an implementation grant; does not block the bounded routing derivation.** I30 `PLAN.md:75–89` requires deferred outcomes so a later exact-block selection can suppress W1. I29 `RETURN.md:18–23,73–85` places its first new-allocation boundary after an assumed already-resident ordinary pass. Those premises disagree on early-terminal invocations.

Continuing after one of these terminals introduces real ordinary/W2/exact-source work, diagnostics, retained results and basis allocations. Calling their routines “ordinary” does not make that extra execution pre-existing or covered by the 20B/60B W1 LME meter.

**Remedy:** derive a bounded arbitration stage before its first new allocation/continuation. Enumerate recoverable W1-trigger terminals versus invalid/ineligible terminals that can still return immediately; preserve the first legacy terminal, its diagnostic prefix and source-budget state separately from exploratory later outcomes. Admit and account the new later-case work/storage, retain actual exact-source charges without a reset or rerun, and explain which accounting governs it. If continuation cannot be admitted, return the preserved ordinary outcome without W1. If later exact-block selects, no W1 attempt/diagnostic/token is allowed and the original terminal/publication bytes must survive. Cover both “early recoverable failure, later exact selection” and “early exact selection, later failure.” Admission must not turn an otherwise publishable ordinary invocation into a block.
