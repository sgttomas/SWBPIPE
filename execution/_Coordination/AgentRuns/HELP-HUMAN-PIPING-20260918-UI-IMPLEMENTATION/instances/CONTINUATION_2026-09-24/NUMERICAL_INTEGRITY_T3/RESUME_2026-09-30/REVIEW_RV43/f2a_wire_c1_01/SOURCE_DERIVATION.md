## Conservation derived from native source

For each chronological native AttemptRecord a, define O(a)=LME(a.work)+LME(a.k4_work), S(a)=shared_work, V(a)=verification_shared_work, and build indicators b_s/b_v. Then full case charge is sum[O+S+V], while actual invocation delta is sum[O+b_s*S+b_v*V]. Work belongs to actual records/calls, not a global source-identity cache. These are mathematical exact totals only while every upstream counter and each projection/conversion remains unsaturated and representable.

`verification_work` and `stop_rule_work` are descriptive subsets already merged into own work/k4_work; the latter includes A1 certification. `stages` likewise describes own work; `shared_stages` includes both shared solve and verification stages. None is an extra additive charge. At 128/256/512 each candidate is verified at 2p; a successful rejected candidate's verification becomes the next candidate in the SAME record (VerificationThenCandidate), so it must not be charged again merely for the role change. Failed verification cannot be reused as a solved candidate. Native chronological records commonly end in Verified, not Accepted; any public candidate-logical view must explicitly carry the paired verification and account for each native record once.

`solve_cases` owns one local group cache per stiffness identity. Repeated `solve_case` calls retain the invocation meter but create new local caches. Every actual new shared build charges the invocation; equality of identities alone cannot justify a false built=false. Cached successful and non-budget failed shared builds charge each new case fully but no new invocation work. Budget-failed builds are NOT cached. A combination merges actual operand caches, taking the first populated slot; it cannot invent one. The same request-spanning meter must survive cases, combinations, failed work and finalization fallback.

Thresholds selected by W1_RESOURCE_POLICY_V1 are 20,000,000,000 LME per case/combination and 60,000,000,000 per actual invocation. Native guards compare spent>room at checkpoints; invocation admission uses charged>=limit. Overshoot is recorded, never clipped. Saturating u64 counters and unchecked additions exist in current source; projection must reject/mark inexact overflow instead of treating MAX or clipped JSON-safe values as exact. Source/graph/encoding/preparation and ordinary/publication/caller work remain outside these native metered units; A1 certificate work is included.

## Source combinations and ordinary algebra

Native retained mechanics is a fresh independent solve of exact combined source load terms and prescribed coupling, rounded once at p, with its own schedule, stop rule, final certificate and case budget. It does not sum operand published/retained displacement values and does not solve ordinary operands on demand. Current RetainedCombination accepts selected RetainedSolve operands only, so a mixed ordinary/W1 facade needs a deliberate source-based interface; forcing ordinary operands through W1 changes their policy and is not a valid shortcut.

Compatibility requires same stiffness bytes, published layout, station fractions/members and support-group memberships, not IDs alone. K4STF includes geometry, members/material section operands, springs/directional springs and constrained DOF set; it omits constraint values, loads, stations and support groups. K4SRC includes those source details; K4CMB binds ordered factor bits and complete operand source identities. A source adapter must bind load IDs/terms and mapping as well as the material/modulus basis. Actual cache ownership remains separate from identity equality.

Existing facade mechanics gates hold: nonlinear supports, constant effort unless factors sum to one under existing predicate, and mixed modulus bases. Range/envelope and labelled result-state subtraction retain their ordinary result algebra and metadata; a linear arithmetic expression alone does not qualify as retained mechanics. Do not add a precision token to their rounded-result sums. Failure/refusal of W1 does not silently delete an otherwise publishable ordinary combination or alter operand standing.
