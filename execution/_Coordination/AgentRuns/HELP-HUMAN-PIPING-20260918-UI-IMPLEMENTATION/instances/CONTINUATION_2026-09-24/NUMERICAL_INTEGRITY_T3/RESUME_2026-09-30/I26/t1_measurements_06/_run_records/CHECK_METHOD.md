# Post-run checking method and boundary

The only measurement command was the original sealed tier_cli, with
PYTHONUNBUFFERED=1 added to the recorded environment and stdout/stderr redirected
to its canonical driver log. No schedule hook, custom driver or supervisory
framework was added. The original runner performed its explicitly granted full
Python catalogue metadata enumeration, including T5 grid recipes, before
filtering W1-T1. This was not a larger product run.

The intended live checks were not achieved: the tier completed before the first
post-launch model tool read. BASELINE_CHECK, FULL_CHECKS and METRIC_WINDOW_CHECKS
are expressly post-run. ROOT acknowledged the deviation and directed completion
of these bounded checks, not a retry. No accepted/qualified-live-run claim follows.

Standard VENV JSON/hash metadata checks reject duplicate JSON keys. Every normal
counts row and fresh W1 binding is compared against its own seed for all37
consumed plus20 invariant fields. Normal source=file and prepass source=computed
are checked separately. W1 starts bind all15 context fields; sparse starts bind
the applicable11. Each of22 fresh W1 estimates must be an integer, nonnegative,
and exactly equal between its prepass and normal process, with positive maximum.
Full normalized record argv is checked against the sealed full-token recipe;
the actual unchanged CLI and runner source bind the absolute paths separately.

For H windows, accepted H19 per-run totals are rebound by
fresh estimate_w1_fixed_bytes minus that variant's Hfixed. compose() adds the
model/Args caller once to every nonzero source, solve and prefix window; unchanged
seed/source and kernel diagnostic fields establish the corresponding kernel.
Rebound full and selected128 moving totals must equal the actual emitted
estimates. No observed heap is used to determine its bound. Requested and moving
metrics remain distinct. Stage heap_current_begin/end and requested peak use
requested bounds; moving peak uses moving bounds. Repeats summary uses max of
source/solve, and prefix summary/individual prefix stages use outer-prefix
bounds. Global/pre-reset/parser/count/serialization fields are preserved outside
that claim, never treated as stage-bound counterexamples. Sparse is not assigned
an H window.

The unchanged runner admission function is replayed only as post-run metadata
arithmetic, using the actual tier baseline, each earlier recorded prefix and
its correct mode/pass-specific count estimate. No future observation enters an
earlier decision. All60 dictionaries match. Existing parity records, five actual
normal repeats, work/storage/source checks and prefix segmentation are inspected
without new tolerances or reclassification. No full historical published-value
equality is asserted.

All91 runner process records report exit0, classificationok and survivors=[];
no owned runner/time/product commands remained at either process snapshot, and
the outer tool session was reaped with exit0. Source/binary/seed/prior files were
rehash-checked after runtime. Canonical raw logs remain in the records directory,
indexed by RAW_RECORDS_MANIFEST; earlier packets are only referenced.
