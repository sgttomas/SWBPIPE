# Actual acquisition method

VENV Python imported only the unchanged archived k6_runner with bytecode writes
disabled. It selected the fourteen descriptors from the sealed JSON manifest,
not schedule(), and used existing run_parameters/binary_argv to validate their
exact normal-plus-counts-only argv. It invoked existing wait_for_quiet_host with
max_wait_s=120 and existing launch once per named model; all existing quiet
thresholds, wrapper, RSS/heap caps and watchdog remained unchanged. Guard5387
was checked before every acquisition. Full tokens, wrapped argv, cwd, environment,
byte lengths, guard/quiet results, timestamps and returned process records are in
EXECUTION.json; no portable normalized argv was used to reconstruct paths.

Every fresh raw JSON object was parsed with duplicate-key rejection. The37-field
consumed map and20-field invariant map supplied field names; expected values came
from each acquired model's own hash-bound seed row. Four computed-row metadata
fields,22 fresh estimate fields,15 start-context fields, positive complete max,
zero repeats, raw kinds start/counts/summary and absent publication dump were
checked before continuing to the next model. Phase observations and old
reference-context estimates were not equality invariants.

Each authorized product counts-only process constructed its named small builtin
model, frames, primitive source, graph/encoding and counts, then returned before
normal admission/solve. No separate Python model generator, full schedule,
run_tier, no-op, numeric admission, normal solve, retry, other model/tier, build,
compiler, new runner/tool, maintained change, Git/index operation or delegation
was executed. There were guard/quiet/time/Python helper processes in addition to
the fourteen product processes. Existing runner sanitization was retained.

After runtime ended and ROOT received the slot release, only JSON/hash/file-set
checks and copying this block's56 new logs into the additive evidence packet
continued. Earlier packet content was referenced by hash/path and not copied.
