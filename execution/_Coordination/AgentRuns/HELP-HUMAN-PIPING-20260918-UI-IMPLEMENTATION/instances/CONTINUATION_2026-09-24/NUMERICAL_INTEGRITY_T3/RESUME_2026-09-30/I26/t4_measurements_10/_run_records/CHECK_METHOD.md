# Finite check method

The existing unchanged wrapper and comparator ran once each. All metadata checks
were one-off calculations using the existing VENV; no replacement runner, guard,
supervisor, comparator or proof programme was introduced. Executed command text
is retained here as run evidence, not an installed or reusable tool.

The full check rejects duplicate JSON keys and truncated lines, checks each
normal/prepass against its model's own 37 consumed plus 20 invariant fields,
checks start flags and all 22 W1 estimates, then applies the independently
reviewed caller deltas and existing H source/solve/prefix window totals.
Current/end/peak requested metrics and moving peaks remain separate. Repeated
summary and outer prefix windows are checked against their matching totals.
Global/pre-reset/parser/count/serialization and all sparse heaps are excluded
from the H bound; RSS projections remain distinct from observed RSS.

All raw repeat outcomes are compared for exact deterministic fields, all
existing parity records must pass, and each observed W1 attempt checks storage
facts, own/shared stage sums, invocation charging and per-precision work.
Prefix endpoints are the unchanged source's ordered segments reconstructed
from the last full call's scalar attempt records; existing prefix parity checks
the prefix call against the full call. No prefix or numerical tolerance changes.

Chronological admission replay calls the unchanged pure admission function
with the prior 108-row journal plus preceding current rows, each fresh W1
binding (or unchanged sparse seed), and the actual current no-op. Eligible
calibration populations are also explicitly listed: eight prior successful
T2/T3 rows per family/mode, 100 or 1,000 members. Same-size T4 rows never calibrate.

R1 completeness is external to its unchanged file loop: all six first-pass
outcomes are rostered, every Selected output has its header/model, unique keys,
six-field row structure, finite value tokens, row class totals and full row count
checked, then its bytes/hash are preserved in the named published-only view.
The comparator uses its exact existing Fraction predicate and references.
Unpublished TREE cases are not input files and receive no passing value result.

The baseline and progress snapshots are actual observations. Baseline was first
inspected while the first normal product was active, not before launch.
Full final checks preceded R1; no exhaustive per-row live-validation claim.
The final normal write timestamps and first completion observation are distinct.
The explicit new CONT-only grant and original deadlines remain separate records.

Successful runner return uses wait4; its default survivors=[] is not a performed
scan. Final ps snapshots separately checked observed groups, all known product
PIDs and exact owned commands. No kill path or universal group scan is credited.
The two comparator environment overrides actually applied are recorded; no
unobserved inherited environment is asserted.

The final outcome table was generated from current T4 raw counters, checked
against FULL_CHECKS/R1_RESULTS and reread before seal. Source/mode/exact set,
ordinary binary, seed, historical/reference bytes and prior working files were
rehash checked; all old journal bytes remain an exact prefix. Independent review
and governed acceptance remain with ROOT.
