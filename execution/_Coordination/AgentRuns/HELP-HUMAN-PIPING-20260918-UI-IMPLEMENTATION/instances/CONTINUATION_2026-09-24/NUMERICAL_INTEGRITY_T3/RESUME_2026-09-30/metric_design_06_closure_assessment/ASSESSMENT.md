The current runner uses C=8GiB and heap cap C-512MiB; its half-heap backstop is
4,026,531,840 bytes. Therefore adopting these coarse uppers as Emax would defer
those VR runs under the unchanged rule. This is **not evidence of actual memory
excess**, nor permission to use a measured peak as the upper. A source-valid but
loose estimate and a useful admission estimate are different achievements.

honest deferral is a valid replay outcome. It does not satisfy an outstanding
measurement requirement by itself. This sparse-tail issue applies to VR's global
consumer; it must not be injected into H's staged W1 bound merely because the
