## Changes

**Eligibility stays held:** `SUMMARY_COVERAGE_COMPLETE = false`.

1. **G5 ladder** (`nativeSchedule`).
   - **Already in place:** a check that the first attempt is fresh, p128, and in record 0. It catches `schedule_fresh_first_p256` with ATTEMPT_MISMATCH.
   - **Added**, in the same function and also as ATTEMPT_MISMATCH: at most 3 attempts, and records present if and only if attempts are. This matches Python's C1a form.
2. **G5b floor.**
   - The draft already compared the p512 floor with Φ(ê) at G5b. It now uses an exported `phi512`, a literal port of `verify.rs` `phi_512` that includes `adaptive::next_up`'s zero-to-least-subnormal rule, and an exported `eHat`, a port of `verify.rs` `e_hat`. Failures are SCALE_MISMATCH.
   - **Unit test** (TypeScript-only). 214 ê words, including subnormal, boundary, MAX and pseudo-random words, are checked against two things:
     - a literal transcription of the native function;
     - the test file's independent exact-fraction least-upper oracle for 2^-438·ê.
     
     It also checks that Φ > 0 if and only if ê > 0, and it checks the `e_hat` coupling.
3. **G5a, unavailable attempts that keep a complete roster** (`unselectedCoverage`), aligned to 05a:
   - **Checks:** the full canonical layout, the feasibility rule, the record bound/theta/data_blocks relations and the direct data facts.
   - **Floor positivity at native p512** now comes from the Run's verification record: Φ > 0 if and only if ê(E_record, L) > 0. This replaces the earlier rule that admitted every floor sign.
   - **No Selection rosters** are applied.
4. **Record-bound rule** (`recordCoverage`, used for both selected and unavailable attempts).
   - `verification.bound` must list every body exactly once, in body order, and an entry is non-null if and only if `has_data`.
   - The no-data theta check now reads the record's theta. For selected cases this equals the selection theta, which G5 binds to it.
5. **Parity confirmations.**
   - **Full canonical layout:** G5a rebuilds the whole layout from the source maps and requires deep equality with `s.layout`, covering order, index, quantity, kind, body and input_derived.
   - **Constraints:** they must now also be unique by DOF, as well as exactly +0.
   - **Empty roster:** a non-null empty roster fails at G3, on the `cov.length >= 1` check.
6. **Must-pass loop.** A new test loops over the corpus `must_pass` array (15 entries). Each applies its edits, rehashes, and must validate with `numerical_eligible=false` and the base case's `expected_classifications`.
7. **Feasibility unit test** (TypeScript-only, covering the L = 0 branch for ROOT's deferral note).
   - `stopFeasible` is exported for this test.
   - Across 2,560 patterns (kind state × L zero or nonzero × floor none or each sign pair), the set of stop vectors it admits must equal exactly the set generated by a row-level transcription of `final_case.rs` `summary_coverage_data`, with D = false.
