enclosing `RESUME_2026-09-30`. Actual source origins, hashes, sealed-basis checks,
commands, logs, candidate hashes and diffs are under `_run_records`.

h_numeric19 with RV30 h_numeric23, the named-profile selection12, context13/16,

bound and total ID bytes minus the other IDs' four-byte minima. This is a bound
on an existing scalar population, not reconstruction of a graph or a source
encoder. All33 reference results still match H19 exactly. Actual captures use
the observed input string lengths or raw global-DOF digits, including the refused
case, without imposing the successful-source shortcuts on a refusal.

Every new descriptor/result is scalar, enum, fixed array or borrowed view.

clone, encoder call, runtime evidence read, build token or sidecar parser. Counts
and loader algorithms retain their original collection and drop edges. This is
source inspection, not a new allocator or RSS measurement. External executable
qualification, input/count provenance and ordinary runtime premises remain real.
