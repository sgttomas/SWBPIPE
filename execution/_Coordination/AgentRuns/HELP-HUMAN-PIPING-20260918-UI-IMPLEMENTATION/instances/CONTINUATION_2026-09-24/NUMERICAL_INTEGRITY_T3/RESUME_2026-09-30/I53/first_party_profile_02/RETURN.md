For each phase metric k and t∈W_J retain:

`E_J = R_J + S_J + Q_J + Σ large L_i + Σ small D_j`.

Here Q_J explicitly includes related ordinary caller ownership Q_ord not already charged elsewhere. Let n[r,call,phase](t) count actual included native contexts, including prior tails, and let C be their qualified per-context capacity maxima. Then:

`Q_J(k,t) ≤ Q_ord(k,t) + Σ n[r,call,phase](t) C[r,call,phase,k]`.

A proved finite δ bounding the summed live context population gives the conservative `Q_context ≤ δ*C_max`. If the synchronous wrapper remains within those callbacks, H≤δ; with the future K admission bound, reply ownership is at most:

`max_(0≤l≤min(K,H)) { l*L_k + (H-l)*D_k }`.

These are finite **conditional** expressions, not chosen multipliers. Present source enforces the logical s/p/c counts and bounds transport submissions; it does not supply δ, H or the transport task-map high-water bound.
