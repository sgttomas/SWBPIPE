## Finite sufficient nonlinear intervals

For any real interval X=[l,u], define m(X)=0 if l<=0<=u, otherwise min(|l|,|u|); M(X)=max(|l|,|u|). Then m(X)<=|x|<=M(X). For signed source bending intervals Y,Z define v-=m(Y)^2+m(Z)^2 and v+=M(Y)^2+M(Z)^2. Choose proved nonnegative outward roots r-,r+ satisfying (r-)²<=v- and (r+)²>=v+. Thus hypot(My,Mz) lies in [r-,r+]. This follows by monotonicity of squares on nonnegative arguments and the norm definition; a fixed outward root format may implement it later. An independent coarse sufficient choice is lower=max(m(Y),m(Z)), upper=M(Y)+M(Z), avoiding roots entirely. Exact nonnegative zero can be retained without inventing an underflow zero. No nearest sqrt, hypot, or sampled corner is itself a bound.

For positive source section modulus [Z-,Z+] and exact positive user SIF i, the endpoint intensified functional i*hypot(My,Mz)/Z lies in [i*r-/Z+, i*r+/Z-]. If a justified SIF interval is used, its nonnegative endpoints must also multiply in the corresponding directions. The source at preview_physics.rs:628–667 actually publishes i*(hypot(my,mz)/member.section_modulus) in Pa. associations(:338–365) binds component/node/member and bend versus branch-header/branch-branch role; it supplies no missing factor default and excludes realized curved macro components. Actual row/role/member/source-reference and final qualified identity must be checked. The proof does not authorize other factors, axial/torsion terms, code stress, an interior SIF maximum, or combined intensified measures.

For endpoint axial interval N and section area [A-,A+], |N|/A lies in [m(N)/A+,M(N)/A-]. Add this interval to the bending norm/Z interval to enclose C_e=|N_e|/A+hypot(My_e,Mz_e)/Z. With no member loads and a uniform admitted section, N is constant and the moment vector is affine. Absolute value and norm are convex; hence C(t)<=max(C_0,C_1), and both endpoints belong to the closed span. Therefore max_span C=max(C_0,C_1). If endpoint C intervals are [l0,u0],[l1,u1], [max(l0,l1),max(u0,u1)] encloses the intended maximum. Correlations between endpoints and geometry can be discarded conservatively. Equality or a constant field does not imply a unique endpoint witness.

The pressure-free open functional is O(t)=|N(t)|/A+|My(t)|/Z+|Mz(t)|/Z, because max(|a+b|,|a-b|)=|a|+b for b>=0. PP lib.rs:11233–11255 uses exactly that outer-max expression before MPa conversion; :9680 onward separately interpolates rounded component values. Using the same m/M operations gives a lower and upper enclosure per endpoint and convexity again gives max_span O=max(O0,O1). This theorem concerns only a genuinely present admitted final open-summary row. It cannot restore a retired row or allow pressure-longitudinal cancellation.
