# Owner decision — K6c historical publication comparison

Status: PROPOSED; not approved and not used to close the protected comparison.
Scope: the KF3 B comparison for the six W1-T4 models only.

## Evidence and authority

The original I21_K6C_IMPLEMENTATION brief requires model-by-model KF3 B outcome
comparison and a stop on changed W1 outcome or published row. RV36's independently
reviewed measurement_plan_02 finds the preserved KF3 records contain source/model
identities, outcomes, selected/verification precision and optional publication
counts, but no full published values or complete publication digest. Available
R1 references are analytic subsets. Matching counts or passing R1 cannot establish
complete historical value equality.

Project AGENTS.md, Software checks, reserves changes to a protected test, tolerance,
oracle or limit to its owner. ROOT therefore cannot silently replace this criterion.
The later comparison closure stays held pending this decision or adequate original
full-value evidence. The first small input-binding step is independent.

## Recommended scoped amendment

For W1-T4, require all of the following:

1. Bind each current model/source to the appropriate preserved KF3 counterpart,
   preserving distinct hash schemes. Compare outcome/reason, selected and
   verification precision, and available publication/unpublishable counts.
   Stop and report changed outcomes, precision or these available row facts.
   An absent publication field remains absent, not fabricated zero.
2. Apply the existing unchanged exact-Fraction R1 predicate and original expected
   subsets/classes: CHAIN103, TREE194 and CONT215 values per orientation where
   publication exists. An unresolved run gets no passing publication comparison.
   Do not change tolerances, expected values, class scales or exception lists.
3. Preserve and check existing W1 source/storage/work/repeat/prefix invariants
   and sparse staged/entry/RCM self-parity. Do not call these a full W1-versus-sparse
   value comparison or a comparison to missing historic rows.
4. Save the full new first-pass published-row dumps and their hashes, for complete
   prospective custody and repeat checks. Preserve all historical evidence.
5. State explicitly in the final K6c return that complete KF3 published-value
   equality was not established, and obtain independent review of the actual
   available-field/analytic/invariant comparisons.

This amendment would discharge that historical comparison obligation at this
explicitly limited scope. It would not establish full historic value equality,
alter solver/publication correctness, relax any numeric tolerance or cap, waive
measurements/gates, qualify F2a, or alter other comparison requirements.

Practical limitation: differences outside the analytic subset cannot be directly
compared value by value with the absent old publication. This is the reason owner
approval is required, even though the numerical checks above remain unchanged.

## Alternative

Retain the original full published-row comparison requirement and keep its closure
held. ROOT would prepare a separate bounded plan for original full-row evidence
or a clearly labeled historical-source baseline regeneration; no such recovery,
old-solver run or new comparator is presently authorized by this proposal.
