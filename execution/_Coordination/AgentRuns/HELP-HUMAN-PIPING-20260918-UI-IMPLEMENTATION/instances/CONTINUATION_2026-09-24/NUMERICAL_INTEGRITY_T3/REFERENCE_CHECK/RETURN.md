## 1. Method (different from R1's)

R1 derives every value from closed forms: tree integration, the force method, the three-moment equation and the M4/M6 formulas. I used **direct-stiffness assembly** instead (`v2_frame.py`), written from Euler–Bernoulli theory in coordinate-free global form:

- the 12-DOF element blocks EA/L·eeᵀ + 12EI/L³·P, ∓6EI/L²·[e]ₓ, GJ/L·eeᵀ + 4EI/L·P and −GJ/L·eeᵀ + 2EI/L·P, where P = I − eeᵀ;
- grounded springs k·ddᵀ/|d|²;
- rigid restraints applied by elimination;
- consistent equivalent loads for the RF-CANCEL spans (qL/2 and ±L²/12·e×q);
- a sparse symmetric elimination in reverse Cuthill–McKee order;
- member invariants recovered from K_e·u_e − f_eq, with the section cut M(x) = −M_i + x·e×F_i + x²/2·e×q.

Arithmetic and π:

- Everything is computed in 110-digit `decimal`, with π from my own Chudnovsky series.
- The RF-MECH nullity, the RF-CANCEL zero detection and the null-motion checks use exact `fractions`, with rational π.
- The tail check uses 400 digits.

Independence:

- I used no R1 helper code.
- Models come from `references.json` → `model`. The abbreviated models (the n = 10000 cases and `RF-MECH-LINE-IN-CHAIN1000`) are regenerated by my own generator (`v2_models.py`). That generator reproduces all 18 complete n = 10, 100 and 1000 RF-LARGE models exactly.
- I compared against R1's numbers only after my derivation had run (`v2_compare.py` and the later scripts). See §8 for exactly what I saw before that.

My solutions close equilibrium to within 8.6e-92 of the class scales. In every member, the end-action torque equals GJ·tw/L.

## 3. ROOT's explicit items

### 3.1 RF-CANCEL scale: I recommend adopting R1's net-governed scale

My rederivation reproduces R1's recommended scale, gross scale and `governed_by` label for every one of the 1585 rows.

**Does the recommended scale ever fall below |exp|?** Yes, in 84 rows, all of them `mixed`:

- the ORTHO and INPLANE bending and translation rows, where the net response is 0.3 % to 2 % of the value;
- the UDL reactions and end moments, where the net response is about 1e-10 of the value.

R1's README §7 says "the scale never goes below |exp|". That is untrue of the published column (F3).

It does no harm, because the predicate uses `max(|exp|, scale)`. Where the scale is below |exp|, the comparison is exactly relative 1e-9. The effective comparison scale is never below |exp|.

**Is it looser than the class rule anywhere?** No. The recommended scale is never above the class scale (1585/1585 rows). It is strictly below the class scale in 238 rows: 154 `net` rows and 84 `mixed`.

**Is it consistent with the unchanged criterion?** Yes. The predicate `|obs − exp| ≤ 1e-9·max(|exp|, scale)` is unchanged, and only the `scale` input differs.

- For `net` rows it is |exp|, so the test is purely relative.
- For `zero` and `other loads only` rows it is the class scale.
- For `mixed` rows it is at least as strict as the class scale.

One point of interface wording remains. The JSON header `criterion` says scale = "the published class scale". If ROOT adopts the recommendation, the package must say that the recommended column is the binding scale for RF-CANCEL (F3). D1 revision 2 already states this (§7.3).

**Why not the gross-governed scale?** My recomputed controls agree with R1's flags in all 161 cases:

- **Gross-governed scale.** It exceeds the class scale in 427 rows. It accepts every binary64 float-sum defect at every G. It accepts the dropped-n defect at G = 1e80.
- **Class scale.** It hides the float-sum defects in the ORTHO and INPLANE variants at G = 1e8 and 1e80, and the dropped-n defect in those variants at G = 1e80.
- **Recommended scale.** It catches every defect that changes the net by more than 1e-9: FS-GnG and FS-nGG fail by 2.48× at G = 1e7 and 9.93× at G = 1e8, and lose the net entirely at 1e80. The UDL controls fail by 1.01× and 2.53× at w = 1e8, and FS-A-node-B loses the net at 1e80.

**Caveat (F2).** Three net-governed rows sit below D1's floor: F-G1e80-GnG-ORTHO `u.N1.UY` at 2.1e-11·S\*, M-G1e80-GnG-ORTHO `u.N1.UY` at 2.5e-11·S\* and F-G1e80-GnG-INPLANE `Mb.M2.mid` at 5.0e-11·S\*. There the recommended scale demands more than D1's stop rule guarantees. Each of those cases also has other net rows above the floor, which discriminate on their own. Per D1 §7.3, the harness flags these three rows as not covered and does not loosen them.
