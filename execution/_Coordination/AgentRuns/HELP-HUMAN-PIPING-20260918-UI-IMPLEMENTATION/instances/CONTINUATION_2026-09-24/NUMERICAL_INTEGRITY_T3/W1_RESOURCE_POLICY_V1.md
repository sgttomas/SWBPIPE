## Basis and actual meaning

The basis is [I29's evidence/options](RESUME_2026-09-30/I29/w1_limits_preparation_01/EVIDENCE_OPTIONS.md)
and [fresh RV40 review](RESUME_2026-09-30/REVIEW_RV40/w1_limits_01/RETURN.md).
ROOT read both and verified their inventory/seal. RV40 independently reconstructs
current H and V-K work, including A1 certificate charges. Option B contains the
current recorded Selected single-case charges; its invocation sum is arithmetic,
not a measured multi-case workload or fixed case-count guarantee. The larger
observed TREE work ends Ceiling, and this allocation stops it on work earlier.
It does not cure or redefine KF3-B1 or promise arbitrary-model availability.

Charge each case complete own/shared/verification-shared and spent failed work.
The invocation pays own work and each actually incurred new shared build once;
this is not a global identity cache across separate calls. One InvocationMeter
must span the actual request and combinations. Preserve source identity, actual
cache scope and all spent work. Never reset the invocation meter per case or clip
reported charges to a threshold.

The existing checkpoints can overshoot. These are stop thresholds, not strict
upper bounds on operations, time, memory or RSS. Unmetered source/graph/encoding,
ordinary/caller and publication work stays explicit; A1's new certificate work
is metered. The exact distinctions and source anchors are in RV40's “Source
semantics to retain.” No deployment latency is selected by this policy.

## Memory remains a design obligation

4,026,531,840 B (3.75 GiB) is a provisional technical target for a complete future
F2a requested-and-moving composition. It is **not an enacted production byte
limit, a present guard, an RSS ceiling or a supported-machine commitment**.
The kernel takes no byte-limit argument; H's observation allocator/backstop is
not a product mechanism. No sum/max of current H single-case estimates supplies
the missing F2a or multi-case proof.

F2a checkpoint0 must resolve RV40-N1: complete source/count preparation, resident
ordinary inputs/results, shared groups/caches, failed/active attempts, retained
states/operands and certificate/publication/caller lifetimes; qualified actual
source/build/input premises; a check before affected allocations; and named
W1-only refusal/release behavior that preserves otherwise publishable ordinary
results and standing. Missing proof, overflow and exceeding an adopted allowance
must be handled explicitly. The final byte allowance and its enforcement return
to ROOT after independent design review; they are not supplied by this file.

Keep all eight T4 RSS forecast misses. Neither the observed multiplier nor a
rounded multiplier is a future upper guarantee. Precision-isolated heap peaks
remain unavailable. Product memory composition and guard qualification cannot be
deferred by pretending the existing dense/observation guards already enforce W1.

The owner's supported-machine, provisional6-GiB dense/observation ceilings,
PHYS-R4/availability and observation framing decisions remain separate, as do
KF3-B1 and KF2's dense screen. A change that blocks an otherwise publishable
ordinary result or changes a published correctness contract needs its owning
disposition. F2a/S-G1 remains unqualified; no engineering or product release follows.
