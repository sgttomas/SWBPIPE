  ruling B), K2B-PIN-LOOP, K2B-PIN-PLUMBING, K2B-PIN-THIRD (ruling 5's required pin mutants);
- I10's own: K2B-FLOOR, K2B-MARGIN-LOW, K2B-MARGIN-HIGH, K2B-EXPONENTS, K2B-SENTINEL,
  K2B-SPRING-UNSCALED, K2B-BLOCK-UNSCALED, K2B-FSRC-UNSCALED, K2B-FSRC-EG, K2B-GUARD,
  K2B-PRODUCT-BOTH, K2B-CENSUS-NO-INTERMEDIATES, K2B-OPERAND-SUBNORMAL, K2B-TRIGGER-DROP,
