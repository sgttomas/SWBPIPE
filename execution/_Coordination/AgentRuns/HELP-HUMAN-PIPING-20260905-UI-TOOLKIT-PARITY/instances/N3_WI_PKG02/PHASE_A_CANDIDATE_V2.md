## Row 20 geometry copy/rotate/mirror
Candidate change kind transform_pipe_run; explicit mode copy or in_place, explicit pipe_refs, explicit transform kind translate/rotate/mirror. Translation has quantity-valued x/y/z; rotation has quantity-valued origin, nonzero finite axis vector and explicit angle+unit; mirror has quantity-valued plane origin and nonzero finite normal. No default axis/origin/angle. Rotation/mirror use model coordinates after conversion through accepted unit functions. Reflection is about supplied plane, not merely sign flip about origin.
Copy requires exact explicit ID map and labels/provenance for every selected pipe and unique endpoint node; no ID reuse, auto-numbering or hidden joining. References between copied nodes/pipes remap; material and section data retain meaning; originals unchanged. In_place retains IDs and requires selected nodes not incident to any unselected pipe to prevent hidden geometry mutation. All modes reject supports, node/pipe primitive loads, components, wind exposure references or unsupported attached engineering data touching affected nodes/pipes: this is a bounded geometry-only slice, with blockers enumerating affected IDs. Do not quietly omit attachments. Copy rejection avoids implying a complete supported/loaded run was cloned.

Reflection support/load transformations, especially moment pseudovectors and restraint-axis behavior, are outside this first bounded slice. Reject source objects with unknown geometry-dependent extension fields instead of retaining uninterpreted orientation data. Preserve pipe scalar properties.
