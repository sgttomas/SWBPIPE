# Display-only numeric API candidate V2
Pure convert_display_quantities_json(request_json) in operation_applier facade (already depends core/units), exported identically wasm and Tauri convert_display_quantities. Request {items:[{id,value,from_unit,to_unit,dimension_id}]}; result items {id,status:converted|unavailable,value?,unit?,message?}. Unit math only core/units Dimension::from_schema_value, unit_by_symbol with dimension, convert_for_dimension; finite input/output check. Temperature vs temperature_interval exact canonical vocabulary. Pressure conversion preserves existing quantity/reference kind: never infer atmospheric pressure or convert gauge to absolute. Unknown units/dimensions/retired aliases fail explicitly. UI SI/US preferred-unit mapping contains symbols only, never constants; async memoization by source value/unit/target/dimension. Pure batch accepts no model and returns no mutation. Core/units serde dependency unnecessary. Façade owner PKG16, UI owner PKG07. Required numeric fixtures: inch/mm, force, temperature absolute and interval, invalid dimension, nonfinite/unknown; native/Wasm identical outputs; UI toggles unchanged JSON/hash/drafts. Unconverted supported-dimension gaps disclosed rather than synthesized. This record is derivative implementation guidance, not new unit authority.
